| Area | Source-supported distinction |
| --- | --- |
| Resolver and entrypoint | Root CMake has an experimental, separate SYCL project. Its resolver chooses local .dp.cpp for .cu inputs and otherwise prefers SYCL-local sources before root fallbacks; the Arc executable target is sycl/src/program/generate.cpp. Use this entrypoint to reason about Arc capability, not root CUDA source lists ([root CMake](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/CMakeLists.txt), [SYCL CMake](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/sycl/CMakeLists.txt)). |
| Build and card | Direct build uses sycl/ with Ninja and icx/icpx. B570 AOT is bmg-g21; bmg-g31 is B70. Top-level build places the executable under build-sycl/sycl/strata while setup expects build-sycl/strata or build-sycl-aot/strata. The helper preserves an existing CMake cache; the Docker base is stable-tagged and the helper flags an old ocloc BMG failure. Pin actual binary, image, compiler/ocloc and driver ([Arc build notes](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/docs/INTEL_ARC.md), [build helper](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/sycl/tools/build.sh), [image](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/sycl/tools/Dockerfile)). Upstream setup says B-series is untested and pictures or long answers may fail ([notice](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/sycl/setup_intel.py)). |
| Launch path | server_intel.py wraps the shared server. strata-sycl.sh runs the configured binary in a container, mounts the repo at /work, shares host /dev/shm by default and forwards selected runtime variables. Defaults include build-sycl-aot/strata, STRATA_VERIFY_DEVICE_PLAN=1, STRATA_VERIFY_NO_HOST=1 and STRATA_STAGER_THREADS=12. The adapter routes BT/BDONE slot lines and pairs LP with the preceding T token. These wrapper defaults do not establish runtime safety qualification ([launcher](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/sycl/serve/strata-sycl.sh), [server adapter](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/sycl/serve/server_intel.py)). |
| Prefill knobs | --prefill N is an explicit batched chunk and needs --native. --prefill auto is cache-sized with an 8192 default cap; auto:16384, auto:32768 or STRATA_PREFILL_AUTO_MAX raise it. Default prefill borrows expert-cache slots for buffers; --no-prefill-borrow keeps that space for the session. Record actual args and memory admission ([engine controls](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/sycl/src/program/generate.cpp)). |
| Decode knobs | --spec 0 is plain decode; MTP uses its configured directory and has a 32768-token default window. --draft mtp or dflash2 selects source; DFlash2 needs a pack and --spec >=2. --batch-mtp is an opt-in for batched slots. These are controls, not evidence of a better setting or accepted draft rate ([engine controls](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/sycl/src/program/generate.cpp)). |
| Quick benchmark | bench.sh invokes tools/strata_bench.py from .venv; the standard benchmark is separate. The quick driver measures client TTFT at first nonempty content/reasoning and records prompt/reuse/read/generated and draft counters when returned. --long targets about 32768 input tokens but caps output at 24 even with --think; agent mode is a separate five-turn cache-reuse workload capped at 64 tokens per turn. Imports ab_engine, agent_turns_bench and serve_load are outside the 20-file source export. Collection does not enforce the maintained gates ([entrypoint](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/bench.sh), [client](https://github.com/Niko1221/Strata/blob/504b143342a9fe1aa8320a7b31e11f5c0ac265c3/tools/strata_bench.py)). |

## Remaining qualification unknowns

No B570 runtime/provider compatibility, resolved model/config argument path, memory admission, numerical behavior, safe execution under prior fault evidence, physical 262144-token context, long thinking generation or throughput conclusion follows from this source audit. Before comparison, close the helper-source gap or use the maintained complete client; apply the maintained gates to actual per-run samples: >=32768 fresh input tokens, zero reuse, client TTFT, and >=1024 generated thinking-on tokens. Keep agent sessions separate and classify MTP from observed acceptance. Workstation-pinned safety settings remain prerequisites, not evidence that this upstream path is qualified.
