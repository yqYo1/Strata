Mechanism and three arms
1 Normal pinned IQ2_S CPU trait pointer, checked Q8_K/nrows1 layout contract.
2 Independent noinline direct_control copy of pinned AVX2 operation schedule.
3 Independent noinline index_candidate copy changing only grid index formation.
No shared templated dot wrapper adds another noinline helper call; the two complete
bodies are separate codegen symbols. Candidate HiSpread spreads two bits into each
byte of a constexpr256xuint64 table. grid_indices memcpy-loads eight low bytes,
interleaves high bytes, and writes eight uint16 indices. First four indices alone
feed scalar iq2s_grid qword loads in original lane order. Even last second-half
8-byte low read lies inside IQ2_S qs/sign object storage. Candidate introduces two
8-element temporary arrays and a data-dependent 2KiB table load; these are disclosed
cost risks, not presumed optimized away.

Both copies retain original block FP16 scale conversion via pinned
GGML_CPU_FP16_TO_FP32 (x86 table lookup in simd-mappings.h), nibble unpacking,
sign xor/sub, q8 loads, maddubs/madd, sumi1/sumi2 update order, block int sum/float
conversion/FMA in increasing block order, exact GGML hsum tree and post0.125.
Safe shared adaptation: memcpy sign bytes into uint16_t[16] rather than C source
uint16 pointer alias. This may add scratch or alter emitted memory access and must
be included in generated-code comparison. No ScaleVecs/gather/pairfusion/pairedQ8
load, default flag, FP reassociation, worker/dispatcher change is present. Gate/Up
are independent complete calls with original finish (g/(1.f+exp(-g)))*u.
