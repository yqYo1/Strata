## Ordered hash and storage contract

At each residual boundary, enqueue a read-only integer hash on the same in-order compute queue after the producer commands already submitted there. The next operation that may overwrite `m.R` is then ordered after the hash without a host wait at every layer/kernel. For any source written on another queue, insert the producer event as an explicit dependency before hashing; never infer cross-queue order from host submission order. Capture `p0,T`, layer number, semantic phase, row-major shape/stride, `D`, element type, prompt/request ID, model and executable identity, source/branch configuration, and hash-version in the record. Include `T`, not only token start, so the short tail has an exact extent. Keep the current model's raw FP32 representation, including signed zero and NaN payload bits; do not normalize or perform floating-point arithmetic. The D target has no padding in `[T,10240]` residual rows. If any implementation uses padded strides, record and hash logical bytes separately from padding and define padding treatment in advance.

A suitable versioned locator is a 128-bit noncryptographic integer fingerprint. One deterministic contract is to bit-reinterpret each FP32 word as `uint32_t`, mix it with its linear index and a fixed domain/version seed using only `uint32_t`/`uint64_t` operations, and produce two independent 64-bit accumulators (for example modulo-2^64 sum and XOR of mixed words); include the exact shape and semantic tuple in the manifest. Use only unsigned arithmetic so wraparound is defined, ensure every index in `[0,T*D)` contributes exactly once, and avoid floating-point reductions or uninitialized lane values. A GPU partial-reduction tree must cover all indices, including a nonmultiple tail; use fixed integer partials and a second deterministic integer fold, with scratch initialized/written for every participating group. The CPU oracle must implement the exact version, seed, index encoding, and word order, verify record completeness/uniqueness/order and metadata, and recompute any retained raw window. Fingerprint equality has finite collision risk and is never proof of mathematical correctness; a mismatch only localizes the first recorded boundary with different fingerprint.

Bound device state independently of the 1.55 TB scan: one reusable partial buffer sized for the largest `T*D`, one 16-byte digest slot for each of the 4,608 semantic records (73,728 bytes), and bounded fixed metadata (at 64 bytes per record, 294,912 bytes; allow a small header). Because each next hash is ordered after the preceding reduction, the partial buffer can be reused; only the final digest for each unique slot remains. Do not allocate a host copy of `m.R` or store stripe digests for every tensor. Queue all hashes as each hook occurs, keep the digest output allocation alive for the complete request, and make one bounded readback batch after the last slot, using a completion event from the compute queue or an explicit event dependency to the copy queue. Host code waits once on that batch before parsing. Record and test the submission/lifetime contract; a pointer must not be rebound, freed, or overwritten before its queued hash reads it.

An error/cancellation path must not treat a partially populated digest table as complete. Drain or wait for the hash queue and readback before releasing or reusing the input/output/scratch allocations. If wait/drain reports an asynchronous error or cannot establish completion, quarantine those buffers and mark the diagnostic incomplete; do not retry the read on a potentially reused pointer and do not trigger forced cleanup that could change original status. Keep explicit `complete`, `error`, `truncated`, submitted-record count, and completed-record count fields. The [Khronos SYCL 2020 queue-order and event contract](https://registry.khronos.org/SYCL/specs/sycl-2020/html/sycl-2020.html) states that `property::queue::in_order` orders commands submitted to that queue, while other queues require explicit event/dependency coordination; this matches the source constraint above.
