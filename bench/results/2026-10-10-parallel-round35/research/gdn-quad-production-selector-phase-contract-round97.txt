## Selector and environment precedence

`gdn_recurrence` at `sycl/src/prefill/kernels.dp.cpp:2897-2904` has process-static `STRATA_GDN_HEAD` (`atoi(value) != 0`) and `STRATA_GDN_REC_HEADS` (presence). It chooses variant 1 for head mode unless serial-head mode is present, otherwise variant 0. These statics, and the statics in the variant function below, mean tests of environment settings require a fresh process per row.

For non-HIP builds, `gdn_recurrence_variant` initializes the process-static `STRATA_GDN_QUAD` value at `:2745-51`: unset or exact `"0"` disables, exact `"1"` enables, any other value throws `invalid_argument` when the variant function is first entered. The parse occurs before the candidate condition, so an invalid value also throws on a variant-1 call. Candidate selection at `:2752-60` requires quad enabled, variant 0, `STRATA_GDN_REC_HEADS` absent, `STRATA_GDN_PIPELINE` unset/nonzero by `atoi`, `STRATA_GDN_KEYHEAD` unset/atoi-zero, and `STRATA_GDN_KEYHEAD_TUNED` unset/atoi-zero. A true return from `gdn_recurrence_quad_variant` handles the call; false falls through to the old route. Candidate submission errors propagate; the dispatcher does not catch them and switch to the old route.

The old selector starts at `:2805`. Presence of `STRATA_GDN_REC_HEADS` forces the serial path even for empty or `"0"` values; `T <= 0` and variant 2 also enter that path (`:2805-25`). Otherwise old `pipe` and `tuned` are process-static (`:2826-30`): pipeline defaults on and uses `atoi != 0`; tuned is on only when `atoi == 1`. The tuned keyhead path runs when both are enabled (`:2831`); SYCL then checks `gdn_keyhead_ok()` for its keyhead route (`:2833+`), otherwise it uses the old pipeline/nonpipeline routes and norm. Quad is compiled out under `__HIPCC__` (`:2745,2762`).

The old kernel bodies and their launch code remain textually present below the inserted candidate gate. That source identity does not establish byte-identical compiled images or performance neutrality after rebuilding.
