## Disposition

**The algebraic candidate is real for Strata's GDN-1 recurrence, but FLA is not a drop-in mapping and its ordinary all-chunk forward storage is unsuitable at physical 262144.** Implementing the WY identity with a custom head mapping is possible in principle. No evidence here establishes that a bounded-memory implementation will be fast, fit beside the existing full-prefill scratch, or pass Strata's existing exact/repeat gates. Keep it conditional; do not advance to implementation until a bounded workspace/dispatch design and a parity discriminator are reviewed. The linked Prysmlabs result is not performance evidence for this target.

## Exact Strata operation and mapping

Frozen constants are `S=128`, `HK=16`, `HV=48`, `C=10240` in `kernels.dp.cpp:26-27`; the recorded model has 48 layers with QSA every fourth layer, hence 36 GDN layers (R33). The `gdn_gates_kernel` (`:437-451`) computes, per value head and token, `g = softplus(ab_alpha + ssm_dt_bias) * ssm_a` and `beta = sigmoid(ab_beta)`. The recurrence applies `exp(g)` to state and uses beta after sigmoid; do not feed raw beta logits, assume beta already sigmoid twice, or pass raw preactivation as gate. `ssm_a` is model-provided and its sign/range must come from the pinned model metadata/weights, not guessed.

`gdn_conv` runs before recurrence, uses persistent 3-row causal-convolution history, and then L2-normalizes Q and K (`gdn_l2_kernel`, `:608+`; dispatch around `:2560`). For recurrence, `h` packs Q at `[qh, S]`, K at `[HK*S + qh*S]`, V at `[2*HK*S + value_head*S]`. Source chooses `qh = value_head % HK` (`gdn_rec_cols_pipe_kernel`, around `:900`), so each of 16 Q/K heads is shared by three interleaved value heads: value heads `h`, `h+16`, `h+32` use Q/K head `h`.

For a state matrix indexed `[key_row, value_head, value_col]`, each value-head lane implements the GDN-1 equations (indices suppressed):

`p_t = S_(t-1)^T k_t`; `d_t = beta_t * (v_t - exp(g_t) * p_t)`; `S_t = exp(g_t) S_(t-1) + k_t d_t^T`; `o_t = S_t^T q_t / sqrt(128)`.

This follows directly from `kv`, `delta`, `s[r]=fma(g,s[r],k[r]*delta)` and output accumulation in `gdn_rec_cols_pipe_kernel` (`:928-963`); the code sums four row-group partials in a fixed order. `gdn_out_norm_kernel` then RMS-normalizes the 128-wide `o`, multiplies by `ssm_norm.weight` (`gamma`) and `sigmoid(z)`, and writes FP16 (`:1646-1664`). The ordinary SYCL default is the pipelined column kernel (`STRATA_GDN_PIPELINE` defaults on, `:2663-2720`); it software-pipelines next-token loads but preserves the token recurrence. Keep Strata's conv, gate construction, output norm/gate and projection semantics intact around any recurrence replacement.

The initial recurrent matrix is session-owned FP32, zeroed on fresh request (`session.cpp:43-49, 144-164`) and then carried in-place across ordinary prompt chunks and later calls; it is not reinitialized at each proposed internal WY block. A full session has 36 independent GDN slices. Each one contains `128*48*128 = 786,432` recurrent floats plus `10,240*3 = 30,720` convolution-history floats: 817,152 floats = 3,268,608 bytes. Full 36-layer state is 117,669,888 bytes (~112.2 MiB), including conv history. The source passes each layer's session slice into `gdn_recurrence` (`prefill.cpp:3654-3666`). Keep that state pointer and conv history ownership unchanged; an internal final partial WY chunk must update only live tokens and return the final recurrence exactly as the serial path does.

## FLA comparison: algebra yes; direct configuration no

Pinned upstream FLA source revision is commit `aaf1e19679e29ffe28769ffa1def140ff4be715c` (2026-10-09). Immutable source links: [`chunk.py`](https://github.com/fla-org/flash-linear-attention/blob/aaf1e19679e29ffe28769ffa1def140ff4be715c/fla/ops/gated_delta_rule/chunk.py), [`chunk_fwd.py`](https://github.com/fla-org/flash-linear-attention/blob/aaf1e19679e29ffe28769ffa1def140ff4be715c/fla/ops/gated_delta_rule/chunk_fwd.py), [`chunk_delta_h.py`](https://github.com/fla-org/flash-linear-attention/blob/aaf1e19679e29ffe28769ffa1def140ff4be715c/fla/ops/common/chunk_delta_h.py). Raw SHA-256 respectively: `11758af8f8c7000526c748c736a51bed7bdf84122bc4ee5a221f47e0d6a2e70b`, `09ab23a57ee31dcda63785ad7e5bd0ff803efebab93ff69c0d05b103b5ae24f6`, `ac9d7c0b841e8bab354ac1e6336b289460709fa5cfa3d466e0d87577b3e5d651`.

At that revision FLA accepts q `[B,T,H,K]`, v `[B,T,HV,V]`, gate and beta `[B,T,HV]`, supports `HV % H == 0`, chunk sizes 16/32/64 and optional initial state (`chunk.py`). Its forward forms chunk-local cumulative gates, computes the lower-triangular KKT matrix / `(I+A)^-1` and WY `w,u`, computes one state `h` per chunk, then forms output and final state (`chunk.py`, `chunk_fwd.py`, `chunk_delta_h.py`). This is the same scalar-decay, scalar-beta delta-rule family. For Strata, set q/k pre-normalization off because they are already normalized; do not use FLA's optional beta sigmoid; convert natural-log gate to base-2 only if the kernel's `exp2` formulation requires `log2(e)` scaling. Preserve Strata's final output norm and sigmoid(z), which are outside recurrence.

**Head grouping is incompatible as indexed.** FLA maps each value head `i_h` to key head `i_h // (HV // H)` (`chunk_fwd.py` at this commit, around the K pointer setup); with `H=16, HV=48` that is contiguous three-value grouping. Strata maps `i_h % 16`, i.e. three interleaved groups. To reuse FLA's convention, transpose/reindex value-head data so FLA heads `(k*3+r)` map to Strata value head `k+16*r`, and map outputs/state back; or write an explicit modulo mapping in a new kernel. This permutation must cover V, beta, gate, state, output norm's z/gamma and output rows consistently. Leaving it as-is pairs weights and state with different heads. Existing Strata direct source's grouped-head layout is authoritative; R33 already documents the related GGUF head-layout trap.

FLA's example `h` workspace is `[B,NT,HV,K,V]` (or V-first) in `chunk_delta_h.py` at this revision, one full FP32 state matrix per chunk when input dtype is FP32. This exposes both the valid chunk algebra and the all-chunk memory problem. Its optional parameters (GVA layout, q/k norm, beta sigmoid, gate modes, state layout) must not silently alter Strata semantics.

## Workspace lower bounds at T=262144

These are arithmetic byte counts, not a device-memory measurement. Assumptions: one sequence, `H=16`, `HV=48`, `K=V=S=128`, FP32 intermediates/state, FLA's standard saved per-chunk state and all-token W/U/A; exclude existing Strata scratch, allocator padding and launch/runtime overhead.

| chunk C | chunks | saved h states `[NT,48,128,128]` | all-token W+U `[T,48,128]` each | all-token A `[T,48,C]` | one-chunk W+U+A+state tile |
|---:|---:|---:|---:|---:|---:|
| 16 | 16,384 | 48 GiB | 12 GiB | 0.75 GiB | 3.80 MiB |
| 32 | 8,192 | 24 GiB | 12 GiB | 1.50 GiB | 4.69 MiB |
| 64 | 4,096 | 12 GiB | 12 GiB | 3.00 GiB | 6.75 MiB |

Thus the listed full-sequence arrays alone consume 60.75 / 37.5 / 27 GiB respectively; `v_new` and output add 6 GiB each at FP32 if materialized separately. Even C=64 has 27 GiB before those buffers; this is not viable on the target card. The one-chunk column is the lower bound for a strictly sequential streaming design (temporary `w,u` of `[48,C,128]`, A `[48,C,C]`, and one `[48,128,128]` h tile), not a proven end-to-end peak. The *existing* Strata code already allocates T-sized GDN QKV, convolution, gate/beta and output buffers in `gdn_set_bytes`; adding even 3.8–6.75 MiB to that allocation does not solve the current total-context footprint.

A bounded design can avoid `NT*HV*S*S` by computing a chunk's WY intermediates, applying it to the current FP32 session state, and carrying only that state into the next chunk. That stores at most one chunk's WY/local matrix and one state per active layer. However, one prompt has 4096 sequential state handoffs at C=64 (16,384 at C=16); a one-kernel-per-chunk serial launch path may forfeit the desired gain. A faster parallel-prefix design needs chunk summaries and a scan; do not assume such summaries are small: FLA's plain `h` saves 3 MiB per chunk per layer at FP32. No source-backed bounded, high-throughput solution has been found. Any proposal must state its extra memory alongside, not instead of, Strata's current T-sized buffers and give physical-262144 peak estimates before implementation.

## Prysmlabs claim verification boundary

The Prysmlabs post is dated 2026-07-21 and describes Qwen3.5 0.8B on M4 Max, chunk size 8, two stages (parallel chunk-local triangular solve then chunk recurrence), reporting 1.54x at synthetic 4096 tokens and 34% of chunk GPU time for its two GDN kernels. It explicitly says reordered FP32 arithmetic can flip near-tie tokens in speculative verification. The post's stated state equations match the broad scalar-decay/rank-one GDN-1 family above. The public Alloy repository linked by the post describes a generic Apple-Silicon compiler/runtime, but does not expose the Qwen3.5 DeltaNet kernel source in its README/source listing; the exact kernel formulas and measurements therefore remain the authors' blog claims rather than independently source-reproduced code. No benchmark number transfers to Strata/B570 or its larger geometry. Sources: [Prysmlabs post](https://www.prysmlabs.ai/blog/gated-deltanet-apple-silicon), [linked Alloy project](https://github.com/rayanht/alloy). The mathematical algorithm has primary paper support in [Parallelizing Linear Transformers with the Delta Rule (NeurIPS 2024)](https://papers.nips.cc/paper_files/paper/2024/file/d13a3eae72366e61dfdc7eea82eeb685-Paper-Conference.pdf) and implemented details in the pinned FLA files above.

## Numerical and integration gates preserved

1. Compare serial baseline and WY on identical captured post-convolution Q/K/V, gates, beta, initial FP32 state, and live T; first use a local mathematical/reference harness only if separately authorized. Compare post-norm FP16 output and FP32 final recurrent state at every chunk handoff; keep conv history byte-identical because the recurrence replacement must not touch it.

Capture all 48 GDN layer states or use the existing full-state gates; residual rows alone do not establish state equality. Keep the existing layer-9/ordinal-7 diagnostics as localization only, not as a substitute for whole-model gates.
3. Record the exact chosen `STRATA_GDN_*` route, chunk/tail sizes, head permutation, gate unit conversion, initial-state pointer, state-after handoff, output normalization and every scratch lifetime. State explicitly whether validation requires numerical tolerance; this audit cannot supply a new one.
