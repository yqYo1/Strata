## Smallest useful next discriminator

First use the exact D executable, model identity, environment and input from the pinned receipt, and keep the original correctness gates. The useful comparison is a qualified baseline and one candidate run under the same new instrumentation, with per-request identity in every record. A prior uninstrumented baseline is not a same-instrumentation control; if only the old baseline is available, label that limitation and do not interpret a hash difference as instrumentation effect. Do not schedule a second full D request as a presumed repeat or describe it as likely to reproduce. Keep the controller's original C failure and failed full-run status visible.

At each existing safe request/chunk boundary, after the producer queue has completed its writes, hash the complete live tensors on device and copy only compact digest records to host. Submit the hash after the producer work on the same in-order queue (or an explicit producer event dependency); submit the readback after the hash. Retain the source allocation and its owning borrow/layout until that queued hash has finished. At relayout/reuse boundaries, drain the hash/readback before rebinding or overwriting its input. Do not insert a host wait between each layer or each kernel: one ordered hash pass per selected boundary, followed by bounded readback, avoids 100s of MB transfer and avoids perturbing every operation. Record queue/event ordering, allocation identity, byte length, logical shape/strides, request/chunk/layer identity, and digest algorithm/version. If the available hook cannot guarantee buffer lifetime and queue order, omit the hash at that point rather than reading a potentially reused allocation.

The first pass should cover all groups/heads, not another 32-row window: (a) every 3,268,608-byte GDN state group for all 36 layers, and (b) complete QSA K and V storage for all 66 layers and both heads, including scale/zero metadata and valid-vs-padding ranges. The localization gives exact first-final-difference targets (GDN model layer 13; QSA model layer 15), but later-layer changes are consequential and need the full map. Hash raw representation bits, with a canonical, documented treatment of padding; report logical live bytes separately from padding. Retain no full tensor dump for this pass. SHA-256 or another specified strong digest is a locator: equal hashes make accidental collision negligible but are not mathematical proof, and do not prove that the computation was correct. A mismatch only identifies the first sampled boundary whose final images differ.

The current state image has 36 × 3,268,608 = 117,669,888 bytes. Each QSA K or V part is 134,215,680 bytes (about 128 MiB, just over a 128 MiB cap); downloading even one complete part violates that cap. Therefore a GPU-side streaming hash/reduction is the smallest complete discriminator. If an implementation cannot hash a full tensor without a large temporary, use fixed-size stripes (for example 1 MiB) into a rolling digest in deterministic byte order and emit only final digest plus stripe descriptors. Do not keep all per-stripe host records. The kernel must preserve raw bits, avoid floating-point reductions, and not mutate inputs. A hash equality is useful for stage narrowing only; upon mismatch, take a bounded raw follow-up window around the earliest mismatching stripe/cell and compare exact bytes on CPU.

## Follow-up only after a boundary mismatch

If complete final-state hashes show the earliest mismatch at GDN model layer 13, add a single staged snapshot at that layer's existing safe boundary: full-chunk hashes of `mixed_h`/`mixed_bf`, QKV, gate/z, alpha and beta halves, output projection, and resulting recurrent state. The round-37 projection audit traces the relevant calls and reports no source-level alias/scratch defect; it also says projection hashes should be taken only with actual compact/BF16X2 route flags recorded. Compare the input images first: a mismatch there puts projections downstream of the first divergence; equal inputs with differing projection outputs then narrow the stage. Use raw bytes only for the first mismatching stage and a bounded row range.

If QSA model layer 15 is the earliest mismatch, hash each complete K/V quantized tensor plus scales/zero metadata at its post-write boundary. If the first mismatch lies at cell 49,155 again, retain only a bounded neighborhood around pool cells 49,152–49,159, both heads and K/V, including scales and zero points; this can distinguish local quantization/write behavior from a broad later difference. The prior fixed window `[98304,98336)` cannot answer that question.

A host oracle should independently parse the compact digest manifest, recompute digests from any retained raw window, validate offsets/strides/padding and compare final states against the qualified baseline. It must not turn equal hashes into a math pass. Continue to run all-head and all-66-state-part comparisons, LP/logprob, all four request IDs, MTP 5/5, lifecycle/completion and full physical 262,144-token checks. A successful diagnostic or early boundary match does not waive any gate.
