Accounting hooks
  After existing ids_h grouping, layer metadata records actual p0/T/K, layer,
  expert population, pair, H/FF, row bytes, up/down offsets, packed layer offset,
  layout version, exact blob bytes and selected actual branch/runtime flags.
  No router IDs are copied or read through new device commands.
  The compute entry records each actual routed expert/ne and whether its actual
  blob is a resident slot. Generic GU/Down counters are added only AFTER each
  original expert_product returns. MMQ records its expert gather/control-path
  exposure and requires zero generic products; it does not claim one matrix
  product call per expert for a grouped MMQ launch. No timings from generic
  service capacities are assigned to MMQ.
  The source planner only retains the already-decided Stager::Job backing-kind;
  it increments no transfer counters. Actual copy submissions are counted only
  after the existing transfers.copy returns, in stage_one, inline issue_until,
  and the existing issuer thread. Final source is that real executed branch:
  source1=resident_cache;2=pinned;3=stager_RAM;4=stager_transient;5=stager_GGUF.
  Existing transfer-ledger join source is 0 for resident,1 for pinned,2 for all
  stager variants. Exact bytes/layer/expert are the same arguments as the real
  transfer call. No extra pinned/blob/transient/source getter is invoked.
  In stream_all, copied-but-unrouted experts are retained in ALL-transfer totals

  copies. Every planned primary transfer must have exactly one real submission

  call must have zero copy; every selected streamed call exactly one.

Reconciliation and bounds
  One heap scratch spans 64 layers x512 experts, with separate main Cell/Meta,
  planned-source and issuer Copy lanes. Source planning precedes issuer start;
  issuer never reads or writes the mutable main validity state. The main folds
  Copy data only after the EXISTING issuer.join. Reset happens at the next
  chunk, after that join. No additional mutex, atomics, waits or events added.
  Scratch is reused; output is one fixed 32MiB allocation; bins are a fixed512
  stack array during folding. No per-expert recording allocation. Scratch is
  approximately 1.4MiB; total added owned heap <34MiB, stack bins <=16KiB on the
  present field layout. Root should verify sizeof under the chosen toolchain.
  Body budget is 32MiB-8192 so the final receipt fits the <=32MiB request budget.
  Any allocation/format/budget/identity/count/pair/copy/branch/coverage failure
  preserves the first reason, suppresses the entire retained histogram, emits
  only an invalid receipt, and continues the unchanged original computation.
  Checks: sum(ne)=T*K per layer; one call per nonzero expert; local rows/calls
  partition all admitted entries (peer=0 because unsupported admission fails);
  one actual GU and Down per generic call; no generic products for MMQ;
  transfer sources/bytes/counts including unrouted stream_all; contiguous chunk
  p0, actual T total==n; one record for each admitted layer/chunk. Byte additions
  are checked, geometry multiplications bounded before role arithmetic.
  Sparse bins sorted by exact(ne,source); branch/pair/owner/geometry are on the
  enclosing layer record. Bin logical_packed_bytes counts selected packed blobs
  presented to the compute route, including resident calls; transfer_bytes is
  separately labeled logical H2D payload, not DRAM/L2/controller/SSD traffic.
  Every record waits in owned host memory until final success. Final success
  is after the original run_impl wait/error checks; destructor handles ordinary
  early-return/unwind after existing issuer/stager guards have joined. Existing
  inner exits have literal invalid receipts inserted before their unchanged

  Service fatal call sites preserve their existing termination and gain a
