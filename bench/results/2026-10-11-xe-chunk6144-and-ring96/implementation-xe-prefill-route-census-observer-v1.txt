API and trust boundary
route_census.validate(lines, *, enabled, h2d_validate, h2d_expectations, n_experts, route_k, moe_layers, nonresident_population=None).
lines is one complete single-stage stderr text or iterable of text lines. CRLF line endings accepted, embedded boundaries rejected. Caller supplies explicitly boolean enablement, its independently qualified unchanged transfer_ledger.validate callable, and all of that validator's explicit geometry/policy expectations. The observer calls that validator on precisely the same captured lines before joining. It does not trust a JSON receipt alone as evidence of independent CPU validation. This preserves the qualified H2D grammar and rejects malformed recognizable H2D families, invalid totals and cross-stage runs through that existing validator. Existing transfer_ledger.py was read but never replaced or modified.
Caller supplies actual pinned model expert count, top K and a set/frozenset of actual model MoE layer IDs. For this model those are512,10 and all48 layer IDs; the parser does not universalize those numbers. Optional exact nonresident-population mapping covers precisely the intersection of stage layers and MoE IDs. Our cache3 gives509 per layer, but no509 constant is used in parser implementation. Caller may supply a full-model MoE ID set for a narrower stage. Legal nonnegative signed source keys have canonical decimal syntax and int64 bounds, device int32 bounds; ledger's caller geometry narrows these to the actual invocation.

Exact semantics
One anchored literal v1 grammar, exact single spaces and field ordering, exact mode/issuer enums, canonical decimal booleans and canonical uint64 counters; trailing fields, malformed recognizable census family/version, overflow, duplicates, missing rows, wrong order, cross-stage/identity/policy mismatches rejected. Source emits all H2D rows, all census rows in matching chunk-major/layer-major order, then the unique existing H2D total. Observer enforces that order, matching every device/lb/le/offset/pos/tokens/layer/mode/issuer against the independently validated H2D rows. All expected census rows must precede that completion marker.
MoE layer requires routing_observed1 and routed_rows==expected_rows==tokens*K with checked multiplication. Non-MoE layer requires observed0 and zero route/call counters plus no direct/group execution policy. Its plan flags remain permitted source facts. active_nonresident<=active_experts<=min(n_experts,routed_rows), active_nonresident+zero_nonresident<=n_experts, resident-active count cannot exceed resident population, positive routed rows require active experts. Exact external population, if provided, must match. All sums use bounded uint64 checks.
Direct and group policies are mutually exclusive and require MMQ; group requires full_nonresident_stream. Group calls require group policy. Direct policy excludes gather wrapper calls. Declined groups require at least as many individual fallback returns. Group/individual/dequant counts cannot exceed active expert occurrences. Native dequant GU/down return counts are paired and MMQ excludes them; non-MMQ excludes gather returns. Canonical H2D format excludes native-only plan/wrapper facts. Global plan_fallback must be stable across invocation and per-layer MMQ flag stable across chunks, but fallback1 with MMQ1 is allowed. A mixed global plan with one MMQ layer and one dequant fallback layer is explicitly represented in selfcheck source. No inference equates global allocation fallback to per-layer fallback execution.
Zero wrapper counters remain valid when no counted host wrapper is needed. No equality is inferred between transfer calls and active_nonresident or zero_nonresident: full-stream H2D may include zero-row experts and CPU/resident paths alter compute participation. No GPU execution, numerical correctness, DMA service, physical bandwidth or request completion is inferred.
Enabled output is JSON-compatible compact full parsed rows, checked aggregate counters, explicit aggregate units/scope and joined H2D total. Routed rows sum layer/chunk row occurrences; expert counts sum layer/chunk expert occurrences, not model-unique experts; call counts sum host wrapper normal returns. completion_declaration checked is a source declaration; independent_completion_validation False and gpu_execution_inferred False. Disabled mode requires explicit enabled=False and absence of both families; returns absent True without rows or fabricated zero aggregates. It makes no model or successful-run claim.
