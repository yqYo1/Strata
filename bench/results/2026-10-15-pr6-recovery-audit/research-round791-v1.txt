# R791 — Localizing precision drift in long-sequence inference

Date: 2026-10-16. Purpose: knowledge collection. This read-only review compares ways to detect and localize numerical drift in deep residual and recurrent sequence inference. It does not assess Strata quality, set an acceptance threshold, or recommend a precision change. I read the assigned scope, artifact-retention rules, current index status, and the limited R782/R783 sections and R785 review that cover type boundaries and kernel contracts. Main’s correction still applies: R783’s FP16 MoE example is separate from the active BF16 path. No local measurements, builds, tests, GPU work, Git commands, or product edits were performed.

## What each measurement answers

A useful diagnostic separates three questions: where tensors first diverge, whether the divergence changes conditional predictions, and whether it changes the task outcome. One scalar cannot answer all three. A per-layer error can locate a difference without showing it matters; a task score can show an effect without saying where it began.

For each producer/consumer boundary, compare aligned rows and tokens and report a distribution, not only a mean: absolute-error RMS and upper quantiles, relative error with a defined denominator/floor, cosine similarity, maximum error, finite/overflow/underflow counts, and the fraction of elements whose error exceeds a chosen diagnostic scale. Keep per-token and per-channel tails. A mean can dilute one rare channel or one short span; a maximum can be dominated by one unrepresentative value; relative error explodes around zero. Norm or cosine alone also loses coordinate information. Record both the raw error and the reference tensor’s scale, so a small absolute difference on a sensitive gate is not hidden by a large residual norm.

The residual stream’s raw magnitude is not a reliable proxy for downstream effect. Chang et al. found, for 3–4-bit weight-only quantization in several transformer LLMs, that lower residual magnitudes could be associated with larger later quantization error because RMSNorm reversed the relative magnitudes. Their early-exit and activation-patching analyses also found that late layers could still adjust output distributions, and that particular MLP gate activations mattered to final NLL. This is useful evidence that localization and impact need linked measurements; it is not evidence about BF16 storage or Strata’s architecture.

For repeated-state models, compare the persistent state after each step on the *same input sequence* and report both state error and state scale over time. Include component-wise tails and state norm/finite checks, plus the next-step output or readout divergence. A large state-vector distance can be harmless if it lies in directions the readout ignores; a small difference in a recurrently sensitive component can persist or grow. Q-S5’s S5 experiments found that task performance was often sensitive to recurrent matrix precision below 8 bits, while other components tolerated more compression; its task-level results establish that component role and task matter, but it does not provide a general state-distance threshold or a 16-bit write-back result.

## Metric comparison

| Evidence | Best use | A misleadingly reassuring or alarming result |
|---|---|---|
| Layer/tensor error distributions | Locate the first store, operator, layer, channel, or sequence region where the candidate departs from its reference. Compare before-store values with values after narrowing and widening. | A low mean or cosine near 1 can hide a rare decisive coordinate; a large L2 can reflect harmless movement in a downstream-insensitive direction or later compensation. A mismatch alone does not establish a prediction change. |
| Recurrent-state trajectory | Find when stored state starts to drift, saturate, decay, or become non-finite under identical inputs; relate each state delta to later outputs. | State distance is not task impact. The same average trajectory error can mask a short critical interval, and a one-step low error says little about a long horizon. |
| Teacher-forced logits, target NLL, and distribution divergence | Compare next-token distributions at identical positions and fixed prefixes; expose changes in confidence even when greedy tokens agree. | Top-1 agreement misses probability shifts; NLL on one target misses changes elsewhere in the vocabulary. A corpus-average can cancel or dilute a small set of bad examples. |
| Generated continuations and end-task outcomes | Check closed-loop behavior and whether the intended task result changes. Use exact-match/accuracy or a task-specific score on a fixed set. | A first near-tie argmax flip changes all later conditioning and makes the rest of two outputs incomparable token by token. A passing small benchmark can miss rare or long-horizon failures; task scores do not localize the cause. |

For logits, collect the complete distribution when feasible: KL divergence in a declared direction (or a symmetric alternative), target-token NLL difference, top-1 agreement, and the reference top-1/top-2 margin. These answer different questions. A substantial redistribution of low-ranked vocabulary mass may raise KL while leaving the chosen token and task result unchanged. Conversely, a tiny perturbation can swap the top two logits when their margin is tiny. If the maximum absolute logit perturbation is bounded by ε, a reference margin greater than 2ε is sufficient to preserve argmax; a small average logit error is not. Teacher-forced NLL is a proper measure of probability assigned to the observed target sequence, not a complete measure of all possible generation behavior.

## Separate storage rounding from operator arithmetic

A 16-bit store rounds the FP32 value written at that boundary. Loading the stored value into FP32 only widens the rounded number; it cannot restore discarded bits. To measure this storage contribution, retain a diagnostic sample of the FP32 value immediately before the store and compare it with the stored-and-widened value, using the same elements and scale statistics.

Local FP32 accumulation is a separate source of difference. For a reduction or matrix operation, feed a local reference the *same already-rounded operands* and compare the kernel’s FP32 accumulator/output before its 16-bit store with a separately validated higher-precision or reference-order result. Record the reduction order and backend, because finite-precision addition is not associative and frameworks may choose different accumulation precision or algorithms. Then measure the store conversion separately. Do not add these local error magnitudes as if later nonlinear operators were linear: normalization, gating, routing and recurrence can amplify, suppress or redirect them. PyTorch’s numerical-accuracy documentation explicitly notes that backend reduction order and accumulation precision may differ and that half-input GEMMs commonly accumulate in FP32, with architecture-specific exceptions. That is a reminder to verify the actual implementation, not assume a universal kernel contract.

## Teacher forcing and closed-loop limits

Teacher-forced evaluation runs both arms on the same tokenized prefix at each position. It holds the input trajectory fixed, so paired logits and target NLL localize how numerical changes alter conditionals on that reference trajectory. Perplexity is the exponential of average token NLL; its value also depends on tokenization, available context, and window/stride protocol. Hugging Face’s fixed-length-model guide explains why disjoint chunks underuse context and why sliding-window choices alter reported perplexity. For comparisons, preserve tokenizer, prompt template, target tokens, context length, mask, and stride.

That control does not reproduce autoregressive feedback. Bengio et al. describe the general teacher-forced versus generated-token mismatch: inference feeds a model’s own previous output, and sequence errors can accumulate. Under greedy decoding, record the first position where tokens differ, the logits/margin immediately before it, and the task result; after that first divergence, later token differences conflate numeric effects with changed context. For sampling, one output pair is noisy even with a shared seed; report multiple fixed seeds or keep teacher-forced distribution metrics as the controlled comparison. Matching generated strings is therefore a behavioral check, while teacher-forced logits/NLL are controlled numerical checks. Neither replaces the other.

## Bounded follow-up protocol

For one fixed model revision and one candidate precision path, freeze 16 long prompts with their token IDs, target continuations, context/window settings, and 128-token generation limits. Run the FP32 reference and candidate independently with identical non-precision settings. During teacher-forced passes, collect per-layer boundary distributions (including pre-store and post-round-trip samples), paired logits/target NLL/KL/top-token margin at every target position, and recurrent-state trajectory summaries at each step. Then run greedy continuations for all 16 prompts and score them with one predeclared task-specific metric; preserve the first token-divergence position and preceding margin. Report all per-example deltas and aggregate medians/tails, rather than only one corpus mean. Add a short local accumulator comparison on selected operators using identical rounded inputs and a higher-precision oracle. Treat this as a localization study: it provides no universal tolerance, quality acceptance threshold, performance result, or full-context certification.

It does not test 16-bit activation storage or recurrent state.
4. Abreu et al., [“Q-S5: Towards Quantized State Space Models”](https://arxiv.org/abs/2406.09477), arXiv 2024. This is S5 PTQ/QAT and task-accuracy evidence across selected dynamical, sMNIST and LRA tasks, not a long-context LLM or per-timestep 16-bit trajectory study.

Bengio et al., [“Scheduled Sampling for Sequence Prediction with Recurrent Neural Networks”](https://proceedings.neurips.cc/paper_files/paper/2015/hash/e995f98d56967d946471af29d7bf99f1-Abstract.html), NeurIPS 2015.
