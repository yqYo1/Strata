## Concrete reader hazard found and implemented

NativeDense retirement can keep Verifier::commit_exec_ because it does not read NativeDense matrices. Canonical retirement cannot: capture_commit passes canonical ssm_norm.weight into gdn_step_norm_multi and canonical indexer.k_norm.weight into native_qsa_indexer_append. Keeping that executable through a canonical arena replacement would retain freed norm pointers. The proposal therefore adds retire_prefill_canonical_commit inside the existing dense-retired lease, after checked pending-commit/stream completion. It checked-destroys commit_exec_ and clears that handle, preserving its completed event and every session/snapshot tensor. The ordinary next capture_commit recreates it against restored full canonical refs. Native-only retirement retains its existing behavior. SessionGraphs retirement and Verifier exec/segments/work retirement remain inside the same existing outer lease.

## Opt-in, source capture and actual ownership

`STRATA_PREFILL_CANONICAL_DENSE_BANK=1` additionally requires startup NativeDense bank1, actual native pack, no keep-canonical, enabled PLE and the supported SYCL single-device route. Unsupported graph-only/GPU-only/stage/vision/split/peer/remote startup configurations reject. Existing long layer-major/MMQ/compact guards remain and every short/default/native-only request retains its original placement policy. The head-release1 combination still rejects in the existing outer guard; no combined head/canonical release is invented.

WeightTable::load gains an optional EngineSnapshot pointer and3GiB payload limit. While the actual startup conversion loop is about to upload each segment, it copies exactly host_src/out_at/out_bytes into a bounded original-engine-form RAM arena shadow: stage_out for BF16-high/F32→F16/FP16-scale widening, stage_in for unchanged segments. No GPU D2H capture, later payload reread, mmap recreation or layer load() is used. Padding is zero in the shadow and is not claimed equal to uninitialized original GPU padding. Every tensor payload is exact. The snapshot records pack directory, owning table/arena identity, original full WeightRef metadata, arena offset and an ordered converted-payload FNV fingerprint; actual source file IDs/offsets/lengths remain in the refs. File content SHA256/token/model identity must additionally be pinned externally by Main. FNV is explicitly noncryptographic. After adoption the snapshot is private immutable payload. Captured arena alignment is explicitly restricted to the current256B layout. Row count is capped16384, names already bounded by the loader parser; the3GiB cap covers arena bytes and metadata overhead is separately bounded by row count, not included in that payload cap. Host allocation failure before capture publication returns failure with original startup owners retained.

Capture-mode staging allocation uses the actual shared allocation classification: only confirmed OOM with null returned owner can return false. Unknown error/null, any error/non-null, and success/null fail-stop. Capture upload, drain and staging-free uncertainty also fail-stop before optimistic source-buffer reuse. Default capture-null loader behavior retains legacy error handling. ABI callers must all be rebuilt.

CanonicalDenseBank adopts only the actual generator cudaMalloc arena variable by reference. Capture.loaded_arena, loaded_table, exact report/arena size, all resident row extents, non-overlap and complete metadata/fingerprint identity are validated before ownership is borrowed. The generator remains the full-arena owner; the component temporarily sets that same variable null when it checked-frees exactly the recorded root pointer, and publishes a new root there only after full restore completion. It never frees tensor aliases or a separately supplied foreign pointer. This assumes the generator's actual allocator root, not a forged external EngineSnapshot; the fixture explicitly rejects an interior pointer and changed metadata/payload. Full-state destruction does not free the generator's arena a second time.

All NativeDense::PackedSource originals must have data=null and resident=false and must be absent from captured canonical rows. keep-canonical is rejected before load and any remaining native/canonical overlap is rejected during adopt before any reader retirement. Therefore canonical movement cannot leave a stale original.data inside NativeDense restoration metadata. Models/configurations requiring such overlap are deliberately unsupported rather than silently rebased.

## Deliberately conservative persistent ownership

This intermediate uses separate fixed native and canonical active-layer banks, plus one explicit persistent canonical pool. It does NOT implement a combined canonical/native/expert adaptive-capacity bank.

The persistent canonical pool contains: every non-layer row by its actual name; all96 HC attention/FFN norms; and every blk.1.ple_* canonical payload. Original ss.ple.w canonical key/value/norm/conv pointers alias the arena; they are not independently owned. After reader retirement the canonical transaction republishes persistent table rows into this new owned pool, withdraws other canonical data refs, frees the old arena and immediately rebinds ALL canonical PleWeights fields: key_bf16/key_codes/key_scales, value_bf16, norm_key/query/conv and conv1d_f16. Native PLE key fields remain under the existing NativeDense withdrawal/private layer-1 overlay/rebind path. Persistent pool lifetime covers every layer, including the final synchronous MTP callback and full restoration; it is freed only after PLE fields point into the new full arena. There is no stale canonical PLE fallback or duplicated uncharged PLE owner.

All96 HC norms remain in the persistent map/table and the private composite overlay, supplying current FFN and next-layer attention lookahead at every boundary. Non-layer canonical input/output helpers resolve retained refs through the same live table. NativeEmbed must be registered before canonical phase admission; MTP target embedding therefore remains on that independent owner rather than a canonical arena pointer. MTP projection graphs/weights and target NativeHead remain independent; no MTP KV/weight graph is retired unnecessarily. The actual SYCL Prefill GEMM path takes current weight pointers per call and does not establish a persistent canonical weight cache in the audited implementation; driver/compiler behavior still needs Main qualification.

The existing private Prefill PLE composition assumed that any overlay ple_key row was native. Combined overlays also contain the current pack's persistent canonical BF16 key. The proposed Prefill seam now distinguishes native_type>=0 (requiring native data/scratch) from a resident canonical key, and composes the latter's canonical key fields into the private PleRun before ready(). Native-only behavior is retained. This prevents the current BF16 key from being incorrectly rejected as a missing native override.

The active immutable overlay is persistent refs + current canonical-layer refs + the native layer projection overlay. Collisions reject. Both existing Prefill current-layer and lookahead LayerViews already use this resolver in the bank base; no production table is rewritten per layer to fake a view, and no full WeightTable copy is made. Persistent publications are changed only once under exclusive retirement and restored once, not used as a per-layer graph workaround.

## One prepare/withdraw/restore boundary

NativeDense gains prepare_layer_bank/cancel_prepared_bank. Preparation allocates its destination while Full and changes no refs/owner; ordinary native-only enter calls that same allocator before its unchanged withdrawal. For canonical opt-in the existing request exclusion reserves canonical active bank+pool (uploads/checks persistent payload) and native bank before any graph retirement or source withdrawal. Confirmed OOM or host planning failure leaves Full owners/publications intact; checked reservation rollback frees only new unsubmitted/completed destinations. No normal reader is resumed independently.

Then the existing main/MTP/Verifier commit/compute/copy drains and SessionGraphs/Verifier retire APIs run, including the new norm-bearing commit exec retirement. Native refs are withdrawn, original native owners released, canonical persistent refs published/nonpersistent rows withdrawn and the exact canonical owner released. Every layer callback drains old readers, activates native then canonical payload, and returns the private combined overlay. Session/KV/GDN/QSA/PLE history, expert cache and residual/workspace state are retained. No inference arithmetic, residual dtype, QSA algorithm or alias policy changes.

On every normal/cancel/error/throw exit the outer guard checks completion, clears the hook, restores NativeDense full owners, restores the original-size canonical arena from captured engine bytes, rebinds full canonical PLE fields and native PLE key, then frees canonical bank/pool, recaptures SessionGraphs and unblocks Verifier. The canonical arena/table is published only after its entire copy has completed and row identity is rechecked. If native succeeds but canonical restore OOM occurs, the reader gate remains closed and the generator fail-stops with the full native owners plus canonical bank/pool/snapshot retained. It does not claim joint success or resume decode; component-level explicit retry is possible only without readers. Unknown allocation/copy/drain/free/retirement/recapture results fail-stop with owners alive. Restore is a joint reader transaction, not simultaneous atomic GPU allocation: no intermediate partial restoration is readable. State rollback/RESTORE is not implemented or inferred.

## Fixtures and qualification limits
