# R1049 review of R1048 — Qwen4Exp GDN boundary

Decision: accept as decision support with material corrections; no implementation or numerical adoption. R1048 is 9,198 bytes (within its 9,500-byte budget), and its hash matches the assignment: 773f9f44b5ea752b07e5b898ee2fd451de7d6ee165d29623597a71a0101c6c9a. Spec and eligibility hashes also match (c88ce1e1… / 6329d10e…). All 15 eligibility-pinned source files pass SHA256 checks.

The report answers a finite new question. Its head bijection is correct for 16 K heads and 48 V heads: local slot l maps to SGLang slot s=3*(l mod 16)+floor(l/16), and s maps back to l=16*(s mod 3)+floor(s/3). SGLang Qwen4Exp inherits Qwen3.5; its projection split and fused helper preserve contiguous V/Z/B/A head order, with three V slots per K head. Strata’s current head%16 recurrence is internally consistent with a different V packing. Local packers copy dense GGUF bytes and do not expose the upstream converter’s row transform, so the report correctly leaves checkpoint alignment unresolved rather than declaring a bug.

Correction R1049-C1 — the adapter also needs a matrix-axis transpose. Strata indexes state as ((r*48+l)*128+c), where r is K and c is V (fused_gdn.cpp:106-110,133-165). SGLang’s recurrent state is [head,V,K], with contiguous (V,K) rows (chunk_delta_h.py:130-149). Thus for matching heads, SGLang[s,c,r] = Strata[l,r,c], in addition to the head gather/scatter. Equal 128x128 dimensions do not remove this transpose. The report’s head-only state permutation is incomplete.

Correction R1049-C2 — distinguish the recurrent carry, per-chunk output scratch, and convolution history. SGLang’s live recurrent accumulator is FP32, but h scratch is allocated with k.new_empty and stored in K dtype for chunk outputs; b_v is also rounded to K dtype before its state update. A/w/u are input dtype, cumulative gate output defaults FP32, and output formation casts A to V dtype (chunk.py, chunk_delta_h.py, chunk_fwd.py, cumsum.py). Strata’s qkv/z, conv buffers, history and recurrent state are FP32, with an FP16 output copy (prefill.cpp:2377-2392; fused_gdn.cpp:260-287). SGLang conv history defaults BF16 while temporal state defaults FP32; SGLANG_MAMBA_CONV_DTYPE and SGLANG_MAMBA_SSM_DTYPE/config can override these (mamba_utils.py:63-107; memory_pool.py:720-750). Keeping local FP32 history is a valid candidate choice, but it is a divergence from default SGLang storage, not a matched boundary.

Correction R1049-C3 — the exact target model config is not pinned. Qwen3Next config defaults to 16 K / 32 V heads and output_gate_type=None; the model reads head counts and RMSNorm epsilon from the loaded config. With no activation override, SGLang RMSNormGated defaults to swish, while local recurrence uses sigmoid(z). Therefore 16/48 and output-gate equivalence are conditional on the actual checkpoint config. Also record Q/K L2-normalization epsilon 1e-6. The report’s source-parametric formulas remain useful, but they do not establish these loaded values.

The source call path is correctly bounded: Triton extend calls chunk GDN with chunk size 64 when that backend is selected; backend selection may choose other implementations. No target runtime, GGUF converter provenance, model quality, performance, or physical-context result follows. The validation recipe is useful, but outgoing FP32 carry after each chunk needs an instrumented reference or staged calls: SGLang h scratch is BF16 and is not that carry.
