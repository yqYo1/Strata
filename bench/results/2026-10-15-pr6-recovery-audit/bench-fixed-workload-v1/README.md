Limit: fixed nonce alone does not guarantee all actual bodies match. Prompt length depends on calibration outputs; agent sessions incorporate generated model replies; client/long-generation templates and source docs also matter. The current long-generation body does not contain Suite.tag; it already uses its version/name/run prefix and calibrated filler size. This patch preserves that template. Its equality still requires matching calibration and actual request hashes. A fixed ID makes tagged prompts reproducible under identical inputs; it neither freezes model outputs nor establishes speed/quality/adoption/full-context/RESTORE qualification.
