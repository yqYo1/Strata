## Finding

I found no concrete source-level defect in V3's bounded KV observer within this review scope. The proposal correctly reports actual per-layer mode, slots, context, format and host-pool presence; reads the resolver's real split-u64 counters; bounds the miss-list read by the checked placed-miss count and `<65536` slot limit; chooses a block strictly earlier than the terminal block; validates both page-table directions; and compares each packed plane for one actual selected prior block. It does not claim all-context payload parity or substitute host geometry for a device counter. Runtime, compile, and physical-context qualification remain unestablished.

## Checks and source evidence

- Actual layout and fallback: proposed `consume_prompt.hpp:21–34` derives mode-0 as `slots == ceil(context/4)` and mode-1 as a partial pool with at least `ceil(requested/4)` slots. Live `src/core/layer.cpp:501–518` applies the 20,480-cell streamed minimum and rounds to four-cell pages. This distinguishes a small 512-context/mode-0 fallback from mode-1 at context 32,768/request 20,480 and context 262,144/request 32,768. The source-level expected physical slot counts are 128, 5,120 and 8,192 pages respectively (resident cells 512, 20,480 and 32,768); they are not measurements.
- Fresh baseline and real control words: `consume_prompt_kv_observer.hpp:41–65` synchronizes the producer stream, checks all twelve actual owners, verifies mode-1 map dimensions/pointers and requires counters/overflow to be zero without resetting reused state. `kv_stream.hpp` defines 16 control words with split u64 counters at `[4:6]`, `[6:8]`, `[8:10]`. Live `src/kernels/sycl/kv_stream.cpp:229–235` stores placed misses in `ctl[2]`, overflow in `ctl[3]`, and increments the corresponding real counters. V3's terminal check at observer lines 67–80 requires one call after baseline, positive placed misses, zero overflow and a placed count no larger than slots.
- Bounded selection and payload access: observer lines 81–110 checks `ctl[2]` and `slots < 65536` before reading at most `slots * sizeof(int32_t)` from `miss_block`; chooses an in-range miss before `(input-1)/4`; then checks the actual `miss_slot`, forward `page_table`, and reverse `slot_block`. It compares one block's K/V planes using the logical block and resident slot strides. Live `kv_stream.cpp:37–63,243–263` uses the same plane order and per-block strides for resolver copies. With the admitted geometry (2 KV heads, page size 4, head dim 256), the resulting payload totals are 8,192 B FP16, 4,224 B INT8 including scales, and 2,304 B Q4. The two fixed buffers are 8,192 B each. This supports a one-selected-prior-block coherence observation only.
- Host alias and faults: manifest hashes the audited facade dependencies. Live `src/sycl/compat.cpp:244–251` confirms the mapped host-USM alias is the same pointer; `:261–268` ignores the direction enum, waits registered queues and performs a checked queue memcpy. Observer lines 38–40 and 45, 69 route failed copies/synchronization to `abort()` with owners retained. This reasoning applies only to the configured SYCL device-0 facade, as the proposal states.
- Lifecycle: the observed producer path matches live source: `src/core/layer.cpp:633–662` allocates authoritative identity-layout host KV backing; prefill's existing stage/append path writes that backing; `src/core/verify.cpp` uses the shared `qsa_kv_resolve` after selection and before attention; `src/core/layer.cpp:732–736` dispatches mode 1 to the normal resolver; resolver publishes the map then copies misses in queue order. Terminal append also writes authoritative host KV. The observer runs only after verifier commit/wait and producer drains in proposed `generate.cpp:7318–7343`. Main's correction remains applicable: this is not evidence that all KV is simultaneously resident or that every selected payload was compared.
- Receipt checker: `verify_receipt.py` requires explicit expected actual mode and resident cells in addition to request/context, terminal T=1, zero output and actual probe fields. Thus a mode-0 fallback cannot pass a mode-1 physical gate. Mode-0 receipts report no streamed payload probe and are checked separately.
