## Source and mapping checks

`src/kernels/sycl/iq.cpp` currently validates type, complete block count, source/output span and two-byte source alignment before dispatch. Generic type 18 has 256 values per 98-byte block. GU validates `width % 256 == 0`, validates both source tensors and output span, and stores the gate/up rows interleaved by logical row. The proposed `bid` maps generic input to `src + bid*98`; for GU, `row=bid/(width/256)`, `col=bid%(width/256)`, source is gate for even logical rows and up for odd rows, and source row is `row/2`. Output `bid*256+j` follows that same gate-row/up-row order. The callers' count checks bound the derived block/output arithmetic; width is positive and divisible by 256 before the GU specialization is reachable.

Each subgroup owns one block. For S=16, the two uniform `half` iterations cover 16 consecutive values each within a 32-value group; for S=32, one iteration covers that group. The fixed 8 groups × 32 values cover exactly j=0..255 with no lane-tail. Workgroups have 4*S local items and round the block count up to four subgroups. The `bid >= blocks` guard is subgroup-uniform, so padded subgroups return before any collective while participating subgroups execute every collective in converged control flow. All input offsets are byte reads. The fixture includes accepted source offsets 0/2, partial final workgroups, several block counts, three GU rows, guards and complete input/output/oracle arrays. No per-lane block access or write crosses the checked block/output spans by inspection.

The v2 arithmetic retains the R617/R619 IQ3_XXS operation order: FP16 `d` conversion; per-group aux decode; `db = d * (0.5f + high_nibble) * 0.5f`; magnitude integer multiply; sign float multiply; repository `f16_from_f32`. A designated lane loads each packed grid index and exchanges it within a 4-lane cluster; another designated lane supplies the shared sign bits within an 8-lane cluster. `select_from_group` permits the remote id to differ among work-items; `group_broadcast` uses the same source lane 0 for all lanes. Required subgroup size S is part of each specialization. Preserve `-fno-fast-math -ffp-contract=off`; source-level order alone does not establish device bit equality, so exact output arrays remain a mandatory gate.
