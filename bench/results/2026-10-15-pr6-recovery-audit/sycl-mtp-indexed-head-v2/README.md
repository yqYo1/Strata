# Indexed MTP head v2 — source proposal only

Not applied, compiled, executed or qualified. Main owns all serial build/test/GPU work after the active benchmark. Only this new directory was written; v1 and root product source were preserved. No Git, process inspection, cleanup or private B reads were performed. Python was used solely to author/reconstruct/hash text, not to import, compile or test product or fixture code. `python` was unavailable; the source authoring scripts used `python3`.

`source.diff` is a complete root-based replacement for v1, not a delta to apply after v1. `reconstruction.json` records exact root-base and output SHA256 for every proposed product file; `pins.json` preserves v1 dependency pins. Large source duplicates are omitted. `author.py` records the deterministic v1 reconstruction and edits; `finalize.py` records fixture-only finishing edits. Main should reconstruct from the patch, verify all pinned hashes, and rebuild all class-layout consumers together. No generated binary exists.

The exact flag `STRATA_SYCL_MTP_INDEXED_HEAD=1` means **prefer indexed where supported**. Default OFF and non-Q6/unsupported geometry retain legacy dispatch. An absent subset retains the legacy full head. A present malformed/unreadable/short/invalid-ID/oversized indexed map rejects before map allocation/publication. No new sampler, Q6 math, quantization, token-order/remap, or generic-kernel restriction is introduced.

R664 overstated its first-forward claim: v1's final eligible branch published `indexed_bind_complete_` and weights, **not** `indexed_head_`; `has_draft_subset()` reads `indexed_head_`. Absence therefore did not by itself prove an indexed first-forward failure. v2 corrects the inconsistent completion metadata: only a successfully uploaded indexed map can complete indexed bind, after coupled setup succeeds. The successful indexed rebind guard and captured-map identity policy remain intact. Legacy fallback keeps legacy rebind semantics; it no longer acquires the incidental indexed-complete marker merely because Q6 geometry is eligible.

A reusable bounded host descriptor reader now checks complete EOF/read status, positive aligned payload, count <= full vocabulary and every ID, preserving duplicates and ordering. Both eligible preflight and bind use it. Preflight only omits copied rows after successful validation; invalid or unreadable input never receives that saving. Existing size-based reservation remains conservative when validation fails. Preflight and bind take independent snapshots before graph capture: file changes between calls are not atomically prevented. Bind always revalidates its own snapshot, and successfully published maps are never reloaded on same-object rebind. Callers must keep startup files stable between reservation and bind. `bind_bytes` still lacks an actual full-weight byte-span parameter; full-span agreement remains a bind gate.

The production MTP capacity check is distinct from the generic indexed entry: `head_logits_` has `max_t * n_vocab` elements, so SYCL bind rejects subset counts above n_vocab before publishing either indexed or legacy subset state. The generic kernel still permits duplicates whose count exceeds full rows. Legacy gather arithmetic/upload behavior otherwise stays as in v1.

All production bind callers found are `src/program/generate.cpp` root lines 4801, 6431 and 6812. They use the same MtpDrafter declared at 2819. The local NativeHead is declared at 2997; v1's checked retirement lease immediately follows it, so it executes before NativeHead destruction at every scope exit. Stage heads are owned by `stages` declared at 2461, before mtp, and outlive mtp. The lease and checked indexed stream/round/step-graph retirement are retained byte-for-byte. KV-only prefill stops before head dispatch. This is a static caller audit, not a runtime lifetime result; arbitrary future callers must retire borrowed readers before replacing their head owner.

Host fixture checks are always on, with no dependence on `assert`/NDEBUG. It calls the actual helper for absence/noneligible decisions, complete/duplicate maps, malformed/short/invalid-ID/over-capacity input, an error-bearing FILE stream, geometry and overflow. It is not a full instantiated MtpDrafter integration fixture. Its `__FILE__` path must remain readable at runtime for the error-stream case.

GPU fixture requires two separate owned invocations, argument `0` then `1`, and sets the explicit exact parameter once before runtime initialization. Each process has 112 small cases (ni 256 and 2560, cols 1..8, seven maps), plus one production-shaped ni=2560/full=248320/subset=106299/T=1 case: 113 cases total. Every captured graph runs three replays; each replay re-poisons indexed output, compares complete output and guards, checks reference stability, finite values and input/map/quantized payload immutability. Small cases retain v1 tails, duplicates, negative spans and invalid-device-ID zero containment. The production case omits repetitive negative checks and contains no timing loop; its device logical payload is under 760 MiB and host live vectors are bounded by the fixed dimensions (allow about 3 GiB host budget). Main must supply the finite deadline, ownership, log budget and fresh fault checks externally. The fixture itself supplies no supervisor.
