Implementation and numerical contract
launch<Format, TransposeQ> instantiates natural/transposed Q storage for modes 0 FP16, 1 int8, 2 q4_0 and 3 int8-K/q4-V. For source dim=lane*8+j, transposed storage index equals j*32+lane, so each score lane reads exactly its original Q dimensions and K values in their original order. Score scaling, max/sum softmax, value fmas and merge order are unchanged. Local sq remains 12*256*4=12288 bytes; sp 12*64*4=3072 bytes; rows 64*8=512 bytes, total 15872 bytes. Existing 256-work-item geometry, subgroup32, query/group/chunk mapping, step masking, negative IDs, nonresident pages and all barriers remain.
qsa_decode_attn_batch_layout(..., n_q, int layout, stream) is SYCL-only and accepts only 0/1, rejecting invalid values before geometry, empty-batch return, pointer validation or queue access. The existing batch API explicitly calls layout0; step still calls the natural batch API. No decoder call sites change. Layout0 preserves existing validation and dispatch. All preexisting geometry/scratch-size/product/span/pool validation is retained in the candidate implementation.
No explicit production device/host allocation, extra wait, copy or launch is introduced. Nonempty batch retains one chunk submit plus one merge submit, the same scratch partition/size, and finish(stream, event). This is a source count, not measured launch evidence. Stream remains an in-order SYCL queue; null stream completes through existing finish; caller must retain buffers and streamed physical KV pages through completion just as before. This change does not add validation for logical IDs beyond what the original source provided: positive IDs and page-table/physical-pool bounds remain the producer's responsibility.
Prefill parses the environment once at initialization. Only exact STRATA_PREFILL_ATTN_LAYOUT=1 enables the SYCL candidate in the existing split fallback branch. Absent/nonexact values retain the original batch call. Presence logs request/effective and states only split fallback is affected, with prompt matrix dispatch unchanged. No STRATA_PROMPT_ATTN_OLD or joint_matrix dispatch changes. Non-SYCL builds keep the original call and report effective0; the new declaration/call is conditional, with no CUDA/HIP kernel implementation or validation.
Current draft_uploads.hpp fixes are untouched.
