# IQ3_XXS subgroup controller v1

SOURCE ONLY / NOT_TESTED / NOT_RUN. Main owns builds, IR review, CPU qualification, GPU, process supervision, and retention. No existing source/controller/benchmark dependency was changed. This directory supplies one controller and manifests; no new process framework, debugger, signal policy or cleanup routine. Unsafe headsplit serial controller is not imported or reused.

Entry: controller.py quick or full, with the project's Python and assertions enabled. Use only after current measurements close. The existing nonblocking exclusive measurement lock prevents overlap. All native work goes through the exact pinned direct_owner.py loaded through owned_stack_probe.load_owner. That Owner owns pidfds, anchored session identities, finite wall/CPU/RSS/text/file/job limits, termination and unreaped-leader/session closure. Controller does not signal, adopt, poll/reap or attach native processes itself. Owner.active remains authoritative even on failure; no final utility starts with unresolved ownership.

Prelaunch build gate: A/iq3xxs-subgroup-build-v2.json must be closed/PASS with unchanged candidate sources, reviewed base, archives, fixture binary and emitted IR. Main's separate A/iq3xxs-subgroup-main-review-v1.json must contain passed=true, complete=true, active=false, IR_review_complete=true, build_receipt_sha256, binary_sha256, device_IR_sha256 matching this exact build, and sg16_supported=true plus sg32_supported=true. Main supplies those fields only after reviewing required subgroup attributes, collective uniformity, source0 broadcasts, FP32 multiply order/no reassociation and actual device admission. Build's initial IR_review_complete=false is deliberately insufficient; missing/pending Main review refuses execution before GPU launch. This controller does not manufacture review evidence.

Eight separate immutable exec arms: off(legacy), on, sg16, sg32, on-sg16, on-sg32, invalid and on-invalid. Invalid is exact SG16. Parallel selector is0/1 and SG selector empty/sg16/sg32/SG16 according to the v2 fixture contract. No environment mutation occurs after native exec. Preserve six established safety flags from historical config; Direct remains0. Each arm gets a separate cache/capture path. Historical failed Direct receipt supplies environment provenance only; its result remains unchanged.

Initial quick diagnostics use flushed UR tracing plus parameter validation. Full also keeps tracing because actual dispatch is an explicit correctness gate; neither mode supplies clean performance samples. UR create names are joined to successful launch handles using Main's previously used parser. Missing/changed trace syntax fails closed. Requested SG16/SG32 must have actual named product launches for generic type18 (20 cases) and GU type18 (10 quick/11 full cases), plus a successful device collective probe. A declined probe or scalar fallback fails this candidate, rather than being called a subgroup success. Per-element launches must be exactly GU21/22/23 (1 quick/2 full each) and generic20/42 (2 quick/3 full each) when parallel1, and none otherwise. Total observed launches must equal3*case_count+6+candidate_probe (213/214 quick,231/232 full). This includes two fixture markers per half case and six F32 calls. Main must review these symbol/count assumptions against emitted IR before qualification; compiler naming changes require a new reviewed version. Structured route evidence and raw trace hash remain recorded; any route validation error preserves raw trace/Owner receipts and stops without retry.

Every candidate is compared against OFF with the pinned v2 whole-array comparator. Prefix/suffix guards, complete inputs/up/oracles/half/F32 outputs and NaN bits remain strict. Only complete, normally reaped, fault-free arms proceed. Fresh journal cursors are recorded per arm and for the job; final faults are attempted even after abnormal native closure. If ownership is unresolved, final fault collection is explicitly incomplete and active remains true. Partial native/collector failure stays FAIL; no original receipt is overwritten.

Fresh output roots: B/main-iq3xxs-subgroup-{quick|full}-root-v1. Receipts: A/iq3xxs-subgroup-{quick|full}-v1.json; compact comparisons: A/iq3xxs-subgroup-{mode}-{arm}-arrays-v1.json. Existing root/receipt refuses retry. Full requires the exact closed quick arrays/routes/fault result, same build/review hashes and all prior owned identities absent/replaced, including rejection of surviving zombies.

Finite launch budgets are recorded before first native exec: quick1GiB job, full2GiB job, each arm192MiB captures, each process32MiB text and192MiB maximum individual file,8GiB RSS,240/900-second quick/full wall. Full eight-arm captures do not fit the old512MiB envelope;2GiB explicitly reserves1536MiB for maximum arm captures,256MiB for process text and remaining room for comparisons/receipts/cache. The same Owner monitors the whole root under every process and stops incomplete on budget breach; there is no silent truncation. Parentless/end-of-job files are compact and no raw cleanup is performed. Retention owner is Main; current consumer is all-arm strict comparison and route extraction at this boundary. Keep one distinct unresolved failure, review successful raw trace/array retirement only after compact evidence is verified and all owners close under the shared lock.
