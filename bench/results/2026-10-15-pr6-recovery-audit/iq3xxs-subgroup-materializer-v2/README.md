# IQ3_XXS subgroup materializer v2

PROPOSAL ONLY; NOT_BUILT / NOT_TESTED / NOT_RUN. Main owns application, tests, builds, GPU, process supervision and adoption. Only this new proposal directory was written. Current product, v1, clean benchmark and existing dependencies remain unchanged.

source.diff applies directly to the current selective product src/kernels/sycl/iq.cpp (Main supplied boundary 6c6b3300; exact content is pinned in source-pins.json). It does not depend on applying the earlier six-type proposal or v1 patch. Full proposed iq.cpp and new iq3xxs_subgroup.hpp are under proposed/. Existing product iq_parallel_decode.hpp is retained, not replaced. No generator is necessary: full source and direct unified patch are both supplied.

The five-role parallel dispatcher remains unchanged: STRATA_SYCL_PARALLEL_IQ_DEQUANT=1 admits GU21/22/23 and generic20/42 only. In particular type18 can never select the per-element implementation. Independent exact STRATA_SYCL_IQ3XXS_SUBGROUP=sg16 or sg32 admits type18 generic/GU FP16 only, after the existing complete span/count/alignment validations. Invalid/missing SG selector, unsupported device width/local limits or launch-range arithmetic admission failure fall through to existing scalar type18, regardless of parallel selector. Other formats and all F32 paths stay on their existing selection. Both selectors default OFF; native environment is immutable from exec onward.

The subgroup header is byte-identical to v1's Main-reviewed header. One subgroup owns a 98-byte/256-value block; four subgroups form one workgroup, with uniform padded-subgroup returns before collectives. Every collective has uniform participation; all broadcasts use source0. select_from_group remote IDs vary legally by four/eight-lane cluster. Block d is loaded once; aux and db are loaded/recomputed separately for each of eight32-value groups. FP32 db and final multiply order plus repository f16 conversion are preserved. Retain -ffp-contract=off and no fast-math/reassociation. Required SG size is part of each kernel's attribute.

Admission returns false only before submission. There is no catch/retry after q.parallel_for or finish; submission/finish failures propagate to the inherited fail-stop ownership path. No alternative kernel is resubmitted after unknown completion. Queue, finish, USM lifetime and public signatures are unchanged. Runtime SG capability or IR lowering has not been measured here.

Fixture: inherits v1's69 quick/75 full public half-array cases, six F32 cases and20 invalid calls, plus separate actual-SG device collective probe. Adds combined on-sg16, on-sg32 and on-invalid arms. Each native process receives its own exact environment. Comparator strictly compares complete source/up/output/guard/oracle arrays, including NaN bits, to OFF and retains all original per-case diagnostic timing samples. It also checks recorded selector combinations. Array equality alone cannot prove which equivalent implementation launched; Main must separately validate actual dispatch/lowering without instrumenting clean speed runs.
