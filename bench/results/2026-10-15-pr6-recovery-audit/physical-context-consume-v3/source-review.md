## Actual SYCL facade copy audit

The observer's mapped-host backing reads were audited against src/sycl/compat.cpp and src/sycl/runtime.cpp, not assumed to be portable CUDA D2H semantics. cudaHostAlloc allocates MemoryKind::Host, which Runtime::Allocation implements with sycl::malloc_host in the owning runtime context. cudaHostGetDevicePointer verifies host USM and returns the exact same pointer as its mapped alias. The configured facade's cudaMemcpy signature ignores cudaMemcpyKind, checks non-null spans, invokes wait_all(), then runtime_for()->wait(queue(nullptr).memcpy(dst,src,bytes)). wait_all checks all registered queues plus runtime completion, and queue() enforces runtime device0 context. The explicit diagnostic admits only this SYCL single-device route; it also checks producer main/MTP/verifier retirement before reads. A failed copy/completion aborts with owners live. Thus copying from the mapped host alias into an ordinary bounded host buffer is implemented as a checked SYCL memcpy, even when the call-site enum says DeviceToHost. This is not an assertion about CUDA/HIP alias directions or another facade. The exact audited source hashes are in the manifest and must match Main's assembly.

## Real counter and plane layout audit

kv_stream.cpp::runs derives one block's planes from rows=n_head_kv*page_size. Current admitted geometry is2 heads*4 cells at head_dim256: F16 K/V each4096B; INT8 K/V codes each2048B plus K/V FP16 scales each64B; Q4 K/V each1152B. Totals are8192/4224/2304B. The observer checks this geometry before using its fixed8192B buffers, excludes streamed hybrid format, and uses the same source/destination plane order and block/slot stride as runs and the actual resolver copy kernel. Pointer offsets are logical probe_block*plane_bytes in authoritative backing and physical probe_slot*plane_bytes in resident pools.

The real resolver sets ctl[2] to placed misses, updates ctl[3] overflow, and increments split-u64 misses at[4:6], lookups at[6:8], calls at[8:10]. Its copy phase uses miss_block[k]/miss_slot[k] for every placed miss, both legacy and grouped copy policies. V3 decodes those actual words, requires the fresh standalone baseline0 then one terminal call and overflow0, and reads only the bounded placed miss list. It selects a real prior block strictly before the terminal page, checks forward/reverse mapping, then compares all packed planes of that selected block. No host geometry count is substituted for a device counter or payload check. This one-block equality is deliberately not all selected/all-context parity. No new kernel, graph, page-map mutation, slot policy, spill or full-KV owner is introduced.

The new observer changes neither graphs nor maps/pools. It allocates no GPU memory and no extra full KV pool. After checked prefill main-queue completion it reads actual per-QSA mode, context, pages, slots, format and host-backing presence. For mode1 it validates map/table ownership and records the existing device control counters with bounded64B reads. It reads the finite miss-block list (bounded by physical slots<65536, at most256KiB metadata), selects an actual missed block strictly before the terminal page, reads its miss slot and forward/reverse map entries, and verifies their agreement. It then copies the exact packed K/V planes of that one prior block from authoritative backing and the normal resolver's GPU slot and compares bytes.
