# R1026 — static safety audit: dedicated QSA prefill scorer

## Decision digest

- **No confirmed bounds, convergence, arithmetic, routing, or queue-order defect found** in the frozen integration at source commit `31415b3bfc7fc6d4ec5fa42cbcf47276ce271811`.
- Tile8 widens pooled-row reads: it loads `pooled[b]` before per-query step/bounds checks. This stays inside the validated full span, so this audit cannot call it an OOB bug; it does change the old no-read behavior for rows a query does not consume and merits an API-contract/test decision.
- The actual-entry fixture covers the public scorer+selector through Strata Runtime, all tile remainders 1–7, and a full tile. It does not execute the `prefill.cpp` route or prove `STRATA_SELECT_OLD`/short-prefill dispatch.
- Keep the prefill-only opt-in and existing top-k flag semantics; add the targeted boundary/route tests below before claiming those behaviors are regression-tested.

## Static safety review

**Bounds and physical context.** `validate` accepts `1<=nq<=65535`, `0<blocks<=INT_MAX`, exact QSA shape and either `active=-1` or `1<=active<=blocks`; `-1` resolves to `blocks` (`qsa_select.cpp:10-17`). Tile8 calls it and validates output `[nq,blocks]`, pooled `[blocks,128]`, dead `[128]`, query `[nq,512]` and steps spans before launch (`:261-269`), using the same `checked_count`/`validate_spans` pattern as baseline. Thus every eager address for `b<active` is within the declared pooled span. Rows skip invalid `n`, inconsistent `nb!=n/4`, `nb>=active`, and `b>nb`; explicit active smaller than blocks therefore requires each query's `nb<active`, as before. The kernel does not enforce physical `n<=262144`; that remains an engine/API contract. At 262144, `nb=65536`; fixture geometry (`capacity/4+2`) accommodates it with 64-bit indices.

**Tiling, collective convergence and tail semantics.** Groups decode as `tile=q0/8`, `b=group%active`, `q0=tile*8`; grid size `ceil(nq/8)*active` covers every valid `(qi,b)` once for 1..256. In a final partial tile, `qi>=nq` continues before steps/query dereference. For each present row, all predicates surrounding five `permute_group_by_xor` operations are group-uniform; surviving lanes use offsets 16,8,4,2,1, and skipped groups execute no collective. There is no group barrier. Per-row key selection uses `dead` only at that row's `b==nb`; each partial tail receives `+1e9f` only if `n%4!=0`; rows with `b>nb` do not write. Product/add order, heads, ReLU and lane reduction match original source (`:54-70`, `:232-247`). The fixture's bit comparison checks tested inputs, but source order alone is not universal binary/codegen proof.

**Eager pooled read: obligation widened, no demonstrated functional bug.** `qsa_select.cpp:42-44` reads pooled row `b` before checking absent query rows, step validity, `b<=nb`, or whether `b==nb` must use dead. Counterexample to prior access behavior: `nq=1,n=1,nb=0,active=-1,blocks=65538`; old scorer reads dead at block 0 and skips later blocks, while tile8 loads all 65,538 pooled rows. With the validated full-span buffer, these addresses are in bounds. The five files do not establish initialization/lifetime of unused rows for callers that initialize only consumed rows. The caller uses a full allocation and scores after append, but initialization/lifetime of every eagerly touched byte is unproven. Therefore this is not a confirmed out-of-bounds bug; it is a changed read obligation and test/API-contract gap. If valid callers may leave unused rows indeterminate, load only after row validation (and preserve dead selection); otherwise record the full-span initialization/lifetime requirement. For `active=-1`, this difference reaches every declared pooled row.

**Alias, queue, capture, error handling.** Baseline and dedicated paths both call `validate_spans`, `queue_for(stream)` and `finish(stream,event)`; the new helper owns no allocation and captures input pointers/geometry. This preserves the same lifetime through completion, alias validation call pattern, queue ordering, and null-stream resolution; shared helper definitions are not among the five files, so their exact guarantees are not independently proven here. The header excludes active bounds for captured graphs; no graph support is claimed. Invalid tile values besides exact `0`/`8` throw before launch; static-local initialization retries if initialization throws. Direct baseline/decode/reference APIs do not consult this parser. The selector flags stay in the separate prefill top-k function and retain their prior exact-`1`/mutually-exclusive behavior.

## Actual-entry fixture and test gaps

The fixture is actual-entry evidence: `tests/sycl/qsa_score_prefill.cpp` directly calls public `qsa_block_scores_prefill` and `qsa_block_topk_prefill` using `runtime_for()`/`Allocation`; it checks score/ID parity, independent ranking, sampled scores, canaries, input immutability and repeat bits. Suite counts 1..9 cover each remainder mod 8 and one second tile; contexts 2051/2052 cover selection-width identity transition. CMake links the fixture with project kernels under C++20 and strict FP options (`cmake/sycl_backend.cmake:421-424`). It covers synthetic API integration, not caller dispatch, model activations or all boundaries.

Recommended additions (gaps, not current bugs):

1. Exercise the actual caller or a focused route seam with immutable per-process environments: tile8 only on layer-major SYCL, `STRATA_SELECT_OLD` original scorer, and short/non-layer-major, decode, reference paths unchanged. The direct fixture never enters `prefill.cpp`.
2. Cover `active=-1`, `active=1/blocks`, invalid 0/>blocks, invalid step records, `n=0..5`, and 262144 (`nb=65536`); verify no-write sentinels and validation-before-launch. Current fixture always passes explicit `active=context/4+1` and uses small contexts.
3. Resolve the eager-read contract with a valid full-span allocation whose unused pooled rows are uninitialized under a device memory checker; optionally add 255/256-query tile cases and fresh-process invalid env strings (`8x`, empty). If API permits uninitialized unused rows, move load behind validation.
