# Native CPU dispatch exposure histogram (source only)

Base: frozen T `7d0105f2a942ac72ca20fef69d4c2e7960653de3`. Branch: `diag/sycl-native-dispatch-histogram-v0141-2026-10-09`.

Set `STRATA_NATIVE_DISPATCH_HISTOGRAM=1` to collect one summary per completed SYCL serve decode request, at the existing decode timing boundaries. This toggle is independent of `STRATA_DECODE_TIMING`; using both helps align scopes. Collection starts after prefill and ends beside the decode timing summary. It covers this pool's native CPU expert jobs, including repeat layer/window exposure, rather than unique expert identities. Other stage pools and non-native jobs are outside this report's scope. Early error returns may skip the summary; the next request resets counters. There are no worker counters, new atomics, timers, task intersections, GPU calls or product UI changes.

The fixed array has 2 phases, 65 type buckets and 9 NT buckets. Type 64 and NT 0 are overflow labels; valid current jobs have types below 64 and NT 1..8. Every nonempty cell prints phase/type/NT/selected branch/eligibility mask/variant and integer expert-job, routed-token and output-row counts. GU output rows each compute gate and up; these are not two separate rows. Expert and token sums must agree between GU and Down. No physical DRAM traffic, timings, hotspots or worker imbalance can be inferred. The line is bounded by 1170 cells and holds no expert IDs or raw events.

GU and Down now share their actual branch resolvers with the caller classifier. The original branch predicates, static setting expressions, order and kernel arguments remain: GU KQ first, the outer `iq512_supported || (!cpu512 && iq256_supported)` guard, IQ512 then IQ256, and ggml fallback; Down KQ, IQ4NL with its original threshold, then ggml. The original kernel bodies, fallback arithmetic and accumulation order are unchanged. The native pool's Q2 direct GU/Down routes are classified ahead of those resolvers using the same `q2_native_kernels` gate and the same AVX512-versus-AVX2 choice as `q2_rows_any`.

Eligibility ignores disabling flags and NT thresholds, while selected labels use resolved static settings from the same functions the workers execute. The header records usable AVX2/AVX512, hybrid status, effective GU512/GU256/KQ/IQ4NL switches, general GU, IQ3S and Down thresholds, resolved gather setting, and compiled/CPU-usable IQ256 variant bits. For non-hybrid CPUs the classifier calls the existing IQ256 variant selector, clears gather for formats without gathered decode, and uses VNNI only for IQ4NL. On hybrid CPUs IQ256/IQ4NL variants are always marked `worker-unresolved:-1`, conservatively even with explicit gather overrides. This prevents host-core attribution to workers. GU threshold values capture the special IQ3S_MT1 rule without re-reading environment flags later.

Disabled collection neither walks jobs nor emits diagnostics. Shared resolver refactoring still affects native wrapper control flow in all builds; it requires root-owned parity qualification before adoption. Diagnostic collection adds caller work; in particular GU classification lies between the original GU-end and FF-quant-end timestamps, so enabled FF-quant/host timings include instrumentation. Do not compare enabled timings as clean performance samples.
