The FIFO/read-identity finding is addressed for a replaced final path component: `lstat` rejects non-regular files before open; `O_NOFOLLOW|O_NONBLOCK` avoids symlink following and blocking on a raced FIFO; the opened descriptor must match pre-open device/inode; then the helper checks ownership, link count, bounds, stable descriptor metadata, and content hash. Parent path components remain caller-trusted, as the implementation report states. A slow regular/network filesystem still requires the external wall deadline.

The final-write self-certification issue is addressed. Errors propagate, and the owner receipt separately requires clean child exit/no signal, stdout marker/hash, and revalidation of files, hashes, lengths, links and modes. The test source covers final record write, fsync, and close failures with false candidate state; those fixtures remain unexecuted here. There is still no multi-file atomicity or directory-fsync claim, so interrupted or failed candidate directories must remain ineligible pending owner inspection.

The narrow rendering/tokenization path remains aligned with the pinned production source: exact source hashes are checked before compiling/executing those bytes in registered modules; no `server.py`, engine, SYCL, GGUF, or weight import is present.
