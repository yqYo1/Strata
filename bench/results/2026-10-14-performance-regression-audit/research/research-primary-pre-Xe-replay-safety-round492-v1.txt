# R492 — Safety gate before replaying the qualified pre-Xe SYCL engine

Read-only source comparison for replay planning. Target donor is integrated Niko 0.1.41 SYCL engine `1eb89482a4afd20277ae0405780ed4f8eb98eb20`; target runtime/source is current primary HEAD `e5ee58cb` (root SYCL backend). No source/Git/worktree change, fetch, build, test, GPU, profiler, or cleanup. The restricted private record and private environment were not read. The measured 32K record is not reclassified as a Xe result.

## Resolver boundary

At 1eb, root CMake enters `sycl/` and returns. `sycl/CMakeLists.txt::strata_resolve` chooses `sycl/src/<path>` when present, else root `src/<path>`; the active prefill, verifier, session, QSA and migrated device code include the overlay copies. At current primary, `cmake/sycl_backend.cmake` directly builds root `src/kernels/sycl`, `src/prefill/sycl`, root core and program sources. A replay of the historical binary must therefore occur in an isolated snapshot of 1eb; do not alter current primary's resolver or point it at the whole old engine to reproduce one component.

## Old safeguards already in the 1eb active overlay

- **Prefill/staging:** active `sycl/src/prefill/prefill.cpp::Prefill::release` drains compute, copy and KV-copy queues before destroying ring/PLE events or freeing host/device storage. `PeerPrefill` drains its queues before freeing. In-order queue is required for reuse/DMA acknowledgements. `STRATA_KV_PREFETCH` is opt-in; its scope drain is present, and the qualified tuned run set it off. `STRATA_KV_STAGE_OWN` prevents prompt staging from borrowing/reassigning expert slots during an A/B.
- **DMA completion:** final 1eb commit adds `sycl/include/strata/event_completion.hpp`: retains the actual async event, serializes generation/query/publication, and does not acknowledge a failed query. Active stager uses the completion object before pinned-buffer reuse; PLE double buffers also retain completion state. This is a real old fix, not functionality to discard.
- **Verifier and graph teardown:** overlay `Verifier` has bounded ring timeouts; timeout raises mapped wait flags and drains relevant compute/copy streams before returning an error. Its live verifier registry is protected by a mutex held across callbacks; destructor unregisters through the same mutex before freeing mapped flags, so callbacks cannot use freed verifier storage. It drains streams before destroying captured graphs/events/buffers. This provides object lifetime exclusion, but the registry is global and release visits every registered verifier, not only a coherent active window. Preserve bounded rescue and drain semantics; do not assume phase precision.
- **Indexer/output/state:** the 1eb source includes the qualified fixes named in the preserved evidence: full-capacity QSA/indexer spare handling, visible speculative commit only after host verdict, typed KV vector accesses, and matched state/output accounting. The physical 262144 lifecycle receipt covers live state, all saved tensor bytes, actual disk restore and normal exit. These are required behavior contracts for any component transplant.
- **Watchdog:** 1eb has progress reporting, blocking-step `allow_until_ms`, and releases verifier waits before abort. On POSIX it uses `std::jthread`/stop token. On Windows it starts a detached `std::thread`; that thread has no joined lifetime boundary. Historical run's explicit `STRATA_WATCHDOG_S` must be taken from the retained receipt; source default is 60 seconds.

## Current-primary protections that are not established by old source

- `cmake/sycl_backend.cmake` requires and propagates `-fsycl-id-queries-range=size_t` to all runtime consumers and device link. Old `sycl/CMakeLists.txt` has no such flag/check. Although old 1eb passed a physical 262144 test under its pinned compiler/runtime, do not carry its CMake unchanged to a different compiler/runtime: first prove the selected old kernels' global-ID arithmetic and launch ranges under the present oneAPI compiler. Keep current size_t range contract for current code; for isolated 1eb replay, adapt the compiler flag only after checking migrated code assumptions, then run the old full-range gate before throughput.
- Current primary has `ScopedWatchdog` lifecycle code: observer stop/join happens before verifier/pool stack objects are torn down on all platforms; a SYCL-specific 300-second default accounts for the observed 89.276-second cold module creation, with explicit env override. Old source defaults to 60 and only POSIX joins. A cold-JIT replay must use an explicit recorded bounded threshold and an all-platform joinable scope; do not rely on the old Windows detached observer. Never “fix” timing by disabling stall handling.
- Current verifier callback access uses a lease-aware `CallbackRegistry` and coherent diagnostic window snapshot; old mutex does prevent destruction during callback but may hold the global lock during a 5-second device drain and releases all live verifiers. Preserve current lifetime/phase improvements when adapting a verifier component; old broad release behavior is not an equivalent active-window contract.

## Safety gate before any isolated replay

1. Pin 1eb tree and the original compiler/runtime/driver/binary receipt; create no current-primary mutation. Confirm `STRATA_ENABLE_SYCL` route, every resolved source path, compile definitions, launch flags and model/KV/context/cache/chunk arguments from retained evidence. Do not reuse only the commit label as binary identity.
2. For the target host/compiler, add a joinable scoped watchdog with explicit stop/join before verifier/pool destruction, and choose a bounded timeout covering known cold JIT; retain the release-and-abort terminal behavior. On old source, avoid detached Windows watchdog.
3. Audit/enable 64-bit global range queries in the isolated compiler path after source compatibility review. Validate checked products for `T*cap`, context positions, indexer block stride, byte counts and grid dimensions before allocating/launching; test the full physical boundary before speed work.
4. Preserve staging ownership: queue drain precedes event destruction/free/rebind; event generation advances monotonically; source host buffer is not reused until its retained DMA event reports complete. KV-prefetch remains off for the matched run unless separately tested with drain/lifetime proof.
5. Keep indexer spare rows, typed alignment/tail path, and visible commit-after-verdict semantics. Run old qualified numerical/state/RESTORE/fault gates before throughput. Any candidate QSA/layout/compact workspace must retain fallback on unsupported shape/device and must not alter speculative visible state.
6. Record current-vs-old method distinction honestly: historical tuned result is two processes × four fresh actual-32K/64-output reads (first separated; six later), while current quiet GEN64 is a different harness. Do not treat read method or output length difference as dismissal; replay both under a matched method before making a new causal claim.

## Unknowns requiring a source/runtime gate, not an assumption

- Whether current oneAPI accepts the old source's generated subgroup assumptions and 64-bit range option without changing migration semantics.
- Whether old callback's mutex-across-device-wait can deadlock with any callback/destructor path on this runtime; source shows safe object exclusion, not a tested liveness proof.
- Whether current callback snapshots/lease code can be cleanly applied to the old `Verifier` without changing its host-doorbell timing or recovery semantics.
- Whether old QSA attention/workspace measurements remain faster under current compiler/runtime and exact 32K int8 geometry. The old composite PP result does not identify a single kernel.

## Decision

The 1eb engine is eligible only for an **isolated historical replay after** watchdog joining, present-toolchain range-contract review, and preservation of its existing queue/event/graph/state safeguards. Its DMA event-completion and full-context/spare/output fixes are already present in the old overlay and should be retained. The current primary's all-platform watchdog join, size_t index-range contract, and callback lease/snapshot model are separate protections and are not proven by old passing receipts. This is a safety gate, not authorization to run or integrate the old engine, and not a recommendation to replace current source wholesale.
