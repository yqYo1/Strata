## What the saved bytes identify

`include/strata/core/layout.hpp:27-65` defines 48 model layers and `qsa_interval=4`; QSA layers are `layer % 4 == 3`, i.e. 3, 7, 11, … . The preceding non-QSA layers map in order to GDN ordinals. Therefore GDN ordinal 7 maps to model layer 9: layers 0,1,2 map to ordinals 0,1,2; layer 3 is QSA; layers 4,5,6 map to 3,4,5; layer 7 is QSA; layer 8 maps to 6; layer 9 maps to 7. The ordinal-7 difference is downstream of GDN layers 0–6 and before QSA layer 11, but this final snapshot does not establish when in token processing the difference arose.

For this geometry, `session.cpp:43-49,96-104` allocates each GDN state as `128*48*128 + 10240*(4-1) = 817,152` floats = 3,268,608 bytes. The localization's `group_bytes=3,268,608` matches one layer. Its first differing byte 22,880,260 is `7*3,268,608 + 4`: byte offset 4 (float index 1) within ordinal 7's state. This validates the ordinal mapping; it does not indicate a bad bound or prove an onset at chunk p0=98304.

## Reset, bounds, and lifetimes checked

- `session_init` sets full-model `gdn_ord0=0`, `gdn_alloc=36`, and carves `gdn_state` for exactly those rows (`sycl/src/core/session.cpp:96-104`). `session_zero` clears the whole owned GDN state (`:144-164`). The serving path calls it for `resume==0` and waits on the main and stage streams before beginning fresh prompt work (`sycl/src/program/generate.cpp:9730-9738`); standalone generate also zeros and waits (`:3758-3764`). A fresh request is therefore intended to start with zero GDN recurrence and convolution history.
- In layer-major prefill, each layer invocation counts prior non-QSA layers, then at GDN layer 9 uses `ss.gdn_state + (gdn_index - ss.gdn_ord0)*gdn_floats` (`sycl/src/prefill/prefill.cpp:3218-3220,3725-3726`). For a full-model session this is ordinal 7; the adjacent conv history begins immediately after the recurrent `128*48*128`-float region. No source-level off-by-one appears in that mapping.
- GDN recurrent state is session storage; the per-chunk GDN scratch is carved separately in `m.region` (`prefill.cpp:1295-1324`). The compact path intentionally aliases `m.y=m.qkv` and places `m.y_h` immediately after its FP32 output (`:1317-1323`), relying on the conv consuming QKV before recurrence writes output. GDN operations are queued in sequence on the admitted in-order compute queue. This intentional temporary overlay does not overlap the `ss.gdn_state` allocation in source.
- `gdn_conv_tiled_kernel` reads each 64-token tile's input QKV and three preceding values, with only the first tile using stored history; `gdn_conv_hist_kernel` then writes the last three input rows (`sycl/src/prefill/kernels.dp.cpp:471-495,593-607`). The recurrence kernel serially processes `T` values per state column and writes the final columns back to the supplied state (`:637-758`). I found no bounded-array or per-chunk indexing defect in these paths that explains an ordinal-7 final-state difference.

## Conclusion and smallest useful next observation

No concrete source defect explains the saved ordinal-7 difference. It is a useful upstream localization: layer 9 is the first changed GDN *saved row* in the final state, and its output can influence QSA layer 11. It is not proof that layer 9 is the temporal first divergence; earlier QSA state snapshots contain KV/indexer state, not the complete attention output/residual, and snapshots are taken after the whole prompt.
