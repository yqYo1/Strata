Change and diagnostic scope:
Five lines after the existing preload_.joinable() guard inspect STRATA_PRELOAD_KERNELS.
Only the exact string "0" disables starting the background thread and its all-kernel-ID
compile sweep. With STRATA_TRACE present, each disabled invocation emits one line:
strata trace: kernel preload disabled by STRATA_PRELOAD_KERNELS=0
Repeated calls while the option remains "0" return without creating a thread.
The option is read on each call, not latched; changing the process environment later
can enable a subsequent call. It does not stop a thread already started.
Absent, empty, or any nonzero/nonexact value leaves the original path unchanged.
The existing joinable guard, stop/join lifecycle, background exception handling,
runtime asynchronous errors, global ERROR matcher, GPU math and kernel dispatch
are unchanged. This is a diagnostic switch, not a fix for JIT compilation errors.
