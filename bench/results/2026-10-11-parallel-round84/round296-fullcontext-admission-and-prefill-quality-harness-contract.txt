Minimal mixed-path teacher-forced quality contract

Use an exact, fixed prefix of P tokens and fixed reference completion `c[0..M)`. Run the candidate’s real chunked Prefill on the prompt’s conditioning rows exactly as production does: `n_batched = n_prompt - 1` (generator around 11137 and 11205), then pass the final prompt token through the normal first verifier row `T=1`. Do not make the long prefix eligible for verifier-window reading. At that first verifier row, use the existing `STRATA_DUMP_FIRST_LOGITS` full-head capture (serve around 10688; standalone around 11817) to score `c[0]` against the logits produced after the final prefix token. This preserves the actual candidate Prefill path for the bulk prefix and includes the first completion-token probability.

Before committing a sampled token, the harness must substitute `c[0]` as the next input. Then feed the remaining fixed completion IDs to `Verifier::run` in bounded windows, compute each next-token score through `Verifier::window_logprobs`, and commit exactly the rows whose inputs are the reference IDs. Row alignment is explicit: first-head row at prefix position `P-1` scores `c[0]`; a window consuming `c[0..k]` scores targets `c[1..k+1]` at positions `P..P+k`. Assert that the score file contains every target position `P..P+M-1` exactly once and that final live state reflects the full prefix plus completion except the final unconsumed target, consistent with existing verifier commit semantics. Record token IDs/hashes, absolute target positions, candidate flags, resume=0 for the prefix, window boundaries, first-head hash, per-token NLL/top-K and final state hash. Keep timing separate.

Existing `STRATA_LOGPOS` alone is not this contract: it records only verifier-window targets, and the current serve `GEN` sampler commits its own first generated token before a later request can continue. `STRATA_DUMP_FIRST_LOGITS` provides the full-vocabulary first row but does not force the reference token. The missing test-harness contract is therefore “capture first row, score `c[0]`, feed `c[0]`, then teacher-force the suffix,” not “route the 64K context through windows.” The separate 262144-cell lifecycle gate must retain a source/binary-specific admission receipt and last-window position assertion; the full-context history cannot stand in for current WNEW or W495 admission proof.
