# Stream-all skipped-slot publication

The threaded stream-all expert walk gives a ring slot back after an entry is consumed. Its copy issuer acquires `a_consumed`, reads the slot's plain `used_of` index and event, then publishes its new copy through `a_issued`. Routed entries already acquire `a_issued` before replacing the slot bookkeeping. Skipped entries previously replaced it directly. A skipped prefix can run ahead far enough to wrap the ring while the issuer still reads that index. The project plain integer access needs host ownership synchronization independently of any SYCL API thread-safety guarantee.

The separate candidate adds the existing `wait_issued(k)` before skipped-slot replacement. It waits for command publication, not DMA completion. The issuer's index/event read precedes its release publication; the consumer acquires that publication before replacing the slot, then releases `a_consumed` for the next wrap. The inline issuer returns immediately from this helper. Routed-only processing, expert bytes, buffers, kernels, arithmetic, event ownership and existing GPU completion checks are unchanged. No GPU timestamps or new GPU commands are added.

On 2026-10-09 JST, a source-bound CPU vector-clock check passes 24 cases: original/candidate pairs for ring sizes 16, 32, 64 and 128 at three wrapped slots each. Every copy obeys the actual ring-credit admission rule. Twelve original schedules permit unordered plain-index read/replacement; the added acquire closes these twelve schedules. The archived summary retains all case results and both complete ring16/slot0 traces. The exact checker reproduces the full private receipt, whose hash is included. This is a deterministic host happens-before model, not an exhaustive proof, runtime race-detector result, or GPU test. It does not establish the cause of any observed GPU hang.

The first model used an invalid warm start for nonzero target slots. Its rejection is preserved. The replacement model explicitly checks credit before every initial or wrapped copy; only that replacement result is accepted.

The source is based on native-copy commit `6caa1421`. Its prefill SHA changes from `6399d65f` to `2b37d84a`, with one acquire call and three comments. The copy-only queue factory is unchanged. The running candidate272 full262144 diagnostic remains on its original source and routed-only ring8; this change has not been compiled, run on the GPU, adopted, or measured. A fresh uniform build and bounded logged 32K A/B/A/B head/state/output gate are required before quiet ring16/ring32 comparisons. Full262144 qualification remains required for any adopted binary/configuration.

On this mostly nonresident native pack, a ring override alone still resolves to routed-only ring8. A stream-all trial also requires `STRATA_PREFILL_STREAM_ALL=1`. That condition copies every nonresident expert, including unused experts, so its performance must be measured. No shorter speed input is planned.
