IMPLEMENTATION
The C++ executable links the actual optional candidate group APIs and unchanged
individual iq_dequant_gu_f16 / iq_dequant_f16. It constructs native block inputs
using pinned ggml-common DECL_CPP layouts, never a second numerical decoder.
All 18 is_iq formats are explicitly enumerated. All device sources use owned,
actual aligned device allocations and declared source extents equal to generated
payload extents. Every source has deterministic expert/projection/block/byte
variation. Gate and up differ; down uses a distinct projection seed. Every native
FP16 scale is overwritten with controlled small finite bits (including separate
min/scale fields for two-half formats). IQ1_M replaces the high four nibbles of
its scale words according to the actual decoder, preserving low integer scale
bits. First blocks exercise signed zero, minimum/maximum subnormal, minimum
normal, negative normal, maximum finite, infinity and quiet NaN. Largest finite
scales may overflow decoded FP16 and nonfinite edge blocks are explicitly not
assumed finite. Native code fields stay within their fixed-width decoder domains.

Every format runs sequential GU and Down arms, null and explicit owned Runtime
stream arms, actual 640x2560 geometry and unusual 3x768 geometry (nine superblocks,
so the eight-superblock launch has a partial tail). Every arm covers n=1..16,
first=0 and first=16-n, exact and padded strides/capacities, and distinct/reused
expert sources. n=16 intentionally duplicates first=0 with identical case counting.
Reused sources map e modulo 3, with references selected from the same arm's
independent individual results. No result can come from another process.

The unchanged individual functions compute all 16 reference slots once per arm,
then an independent host layout reconstruction inserts those exact FP16 bytes
into the active output spans. The group output is compared over the complete
allocated output: active payload, GU row interleaving, Down flat layout, inactive
slots, stride padding and both outer guards. Entire allocated source buffers
including padding and guards are compared unchanged at arm closure. Individual
reference output guards are checked before reference extraction.

Each comparison reports FNV-1a-64 reference/output fingerprints; input fingerprints
are printed before upload. These supplementary noncryptographic fingerprints do
not substitute for full byte equality. Artifact and dependency hashes are SHA256.
Every differing offset is emitted exactly, up to a finite 1,024-offset limit.
Hitting that limit exits as an incomplete comparison, never PASS; smaller failures
also fail after complete scan. No tensor/session/raw capture is created.

The compute queue must be in-order, owned by Runtime, on its device/context with
