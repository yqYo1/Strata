## Minimum gates for this replay

1. Keep the replay on the isolated 1eb tree and its active `sycl/` resolver path. `sycl/CMakeLists.txt::strata_resolve` selects migrated `sycl/src` copies before root sources. The caller must retain the clean source/binary identity and old-runtime/build receipt described in R493; do not mix UR adapters/runtime stacks. This is a replay-identity gate, not a reason to rebuild or mutate the primary tree.
2. Set `STRATA_WATCHDOG_S=300` for the planned cold-JIT run, retain nonzero bounded watchdog behavior, and retain the old POSIX `std::jthread` stop/join code. The 300-second value is an override for the source's 60-second default, not a source edit. Leave DirectSubmission and copy-offload conservative controls at the already selected values; do not turn them on for this replay.
3. Keep `STRATA_KV_PREFETCH=0` and the qualified own-stage configuration. On the success path, `Prefill::run_impl` waits for compute (`prefill.cpp:5212`), expert-copy DMA (`:5231`), and only waits the KV queue when prefetch is enabled (`:5249`). `Prefill::release` drains compute and copy before destroying the Stager, then drains KV before releasing allocations (`:806-839`). Thus no extra queue wait or host-task mechanism is needed for the planned off-prefetch success case.
4. Treat any returned prefill error, thrown queue wait, or nonzero/fault exit as a failed replay; do not reuse the same session or borrowed storage after an unclassified failed queue fence. Native `generate` reports prompt failure and returns fatal (`generate.cpp:11730-11733`); serve prompt failure also returns fatal (`:10299-10316`). Destruction then reaches the existing queue-drain owner. A failed `wait_and_throw` is fail-stop in these owning destructors, rather than proof that memory is safe to reuse. The planned clean throughput run need only record normal completion and exit; no fault injection is required.

## Requested source checks

**Typed KV access.** The old QSA XMX path uses explicit `sycl::vec<int8_t,8>` loads for int8 V-quants and `sycl::vec<uint16_t,8>` for 16-bit V-pool values (`sycl/src/kernels/cuda/qsa_prompt_attn_xmx.dp.cpp:185-190`). The address increments are 8 elements per piece; for the qualified fixed head geometry these are full vector pieces, not a scalar tail. Keep the same int8 KV format and selected kernel geometry for the replay. I found no mismatched element type or partial-vector tail in this selected access. This does not certify arbitrary KV formats or geometry.

**DMA event completion and Stager lifetime.** `EventCompletion` retains the actual event and generation under a mutex; a failed or incomplete query cannot publish completion (`sycl/include/strata/event_completion.hpp:26-45`). `Stager::issued_one` records the returned DMA event; its worker checks `buffer_free` before overwriting a ring slot, and `Stager::~Stager` finishes, signals quit, joins all workers, then frees pinned buffers (`prefill.cpp:423-431, 518-536`). `Prefill::release` waits `m.copy` before resetting the Stager (`:816-818`). These are real retirement protections in the replayed old path. A query exception is not converted to an acknowledgement; it remains a fail-stop risk, not a discovered unsafe reuse call.

**Verifier registry lock.** `release_live_verifiers` holds `g_verifier_mutex` while visiting live verifiers and calling bounded `release_gpu_waits(5000)`; unregister takes that same mutex before object teardown (`core/verify.cpp:201-243, 271-298, 374-379`). This establishes lifetime exclusion for the watchdog callback. It can delay a concurrent unregister while releasing GPU waits; on this single-device target it visits the registered verifier(s), and the 5-second device drain is bounded. I found no callback/destructor lock cycle in the reviewed path. It is not a clean-run blocker; retain the mutex and bounded release behavior.

**Global-ID/grid arithmetic.** The indexer rejects capacity above `INT32_MAX` and rejects `pos_base + max_cells > INT32_MAX`; its output positions and pooled indexing use 64-bit intermediates (`native_qsa_indexer.dp.cpp:385-400, 481-488, 529-561`). At the replay's recorded `max_cells=262144`, block count is at most 65,536; its `unsigned(hi-first+1)` launch extent is therefore in range. I found no global-ID overflow for this specified replay shape. Many migrated kernels narrow group coordinates to `int`, but at the actual historical 32K prompt / 262K context workload their launched dimensions are bounded by model dimensions and chunk/window sizes, not by a multi-billion-element grid. The newer primary's `-fsycl-id-queries-range=size_t` contract remains relevant for current primary long-context source; it is not, by itself, a reason to block this old-source 262K replay with its matching oneAPI compiler. If Main instead builds this source under a different compiler/runtime, the changed compiler contract must be checked in that build, as R493 already records; no source evidence here identifies an overflowing launch in the qualified workload.

**Prefill and KV-copy completion.** The planned run has KV prefetch off. The success path's compute/copy fences precede return; the optional KV fence is only needed if the opt-in path is active. The layer-major route also drains `m.copy` and joins Stager work at its per-layer boundary (`prefill.cpp:2702-2708`) and uses a scope guard to restore resources. On early failures the ordinary route returns an error; its caller is fatal rather than continuing a later request over the same session. Therefore no missing normal-success completion edge or dangerous continuing call was found for the requested configuration.

**Linux watchdog lifetime.** Unlike the Windows detached branch (irrelevant here), Linux declares a `std::jthread` with a stop-token check after each one-second sleep (`generate.cpp:8388-8407`). On ordinary shutdown it closes input, requests stop, explicitly joins, then begins SYCL shutdown (`:11604-11612`). On earlier scope exit, `jthread` destruction also requests stop and joins. Its lifetime is therefore joined on Linux before its enclosing serve scope exits; I found no Linux use-after-free of the verifier registry callback. Keep this scope and the explicit normal-shutdown join. `STRATA_WATCHDOG_S=300` avoids the known cold-JIT false timeout while preserving the bounded failure path.

## Decision

For the planned single-device, KV-prefetch-off replay at the qualified 262,144 context, the source checks found no dangerous normal call site in typed KV access, DMA event retirement, verifier lock exclusion, bounded indexer arithmetic, queue completion, or Linux watchdog lifetime. The minimum concrete gates are: retain the isolated old source/runtime identity, use the bounded 300-second watchdog override, keep the specified conservative DirectSubmission/copy-offload settings and KV prefetch off, preserve all event/queue/registry/jthread code unchanged, and accept only a normal error-free exit as throughput evidence. Do not add an unrelated Windows-detach gate or require a blanket source-wide ID rewrite for this workload. A compiler/runtime change or a larger-than-qualified launch shape reopens the relevant range/ABI gate.
