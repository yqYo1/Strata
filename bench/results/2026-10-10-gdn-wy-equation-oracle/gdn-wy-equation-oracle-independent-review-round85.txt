## Equation and source cross-check

Let `a_i=exp(g_i)`, `G_i=sum_{r<=i}g_r`, `P_i=exp(G_i)`, and the scalar reference use `p_i=S_(i-1)^T k_i`, `d_i=beta_i(v_i-a_i p_i)`, `S_i=a_i S_(i-1)+k_i d_i^T`, `o_i=S_i^T q_i/sqrt(K)`. This is the GDN-1 update in the primary ICLR 2025 paper, Eq. 10, and the source recurrence reviewed in R82 (`gdn_rec_cols_pipe_kernel`); see [Gated Delta Networks, §3.1 and §3.3](https://proceedings.iclr.cc/paper_files/paper/2025/file/4904fad153f6434a7bcf04465d4be2cc-Paper-Conference.pdf) and [R82](gdn-chunkwise-wy-config-parity-and-workspace-round82.txt).

Expanding the state gives `S_i=P_i S_start + sum_{j<=i} exp(G_i-G_j) k_j d_j^T`. Substituting its `i-1` form into `d_i` yields `d_i + beta_i sum_{j<i} exp(G_i-G_j)(k_i^T k_j)d_j = beta_i v_i - beta_i P_i k_i^T S_start`. Thus the unit-lower-triangular system `L D = diag(beta)V - diag(beta P)K S_start`, with `L_ij=beta_i exp(G_i-G_j) k_i^T k_j` below diagonal, is correct. Solving separately for `U` and `W` before reading `S_start`, then `D=U-W S_start`, matches implementation (`wy`, lines 81–99). The resulting output is `P_i S_start^T q_i + sum_{j<=i}exp(G_i-G_j)(q_i^T k_j)D_j`, scaled by `1/sqrt(K)`; final carried state is `P_last S_start + sum_j exp(G_last-G_j)k_j D_j^T` (`wy`, lines 100–109). Ratios are computed as exponentials of prefix-log differences, avoiding division by a possibly small cumulative product.

The scalar path updates the state before output and uses the prior state to form its projection (`serial`, lines 68–78), as the production recurrence does. WY output likewise uses `S_start` plus all deltas through row `i` (inclusive). No one-token lag, post-update projection, or beta/gate swap is present. `beta` is consumed as an already supplied factor and `g` as a natural-log gate; fixture creation does not re-sigmoid beta. `P_i`/`exp(g_i)` factors are placed consistently in L, W RHS, output, and final state.

Head mapping and carries: `key_head()` uses `h % 16` for all 48 value heads (line 21), consistent with R82's frozen Strata mapping; the intentionally wrong `h/3` map is isolated to the negative control. State indexing is `[key_row,value_head,value_column]` (line 20). Both algorithms receive the same initial state and carry only final state across internal chunks; no per-chunk reinitialization occurs (`run`, lines 113–136). All 48 heads are iterated. Partial tails use `live=min(C,T-start)` and only live input/output regions are consumed/written. For T=0 the loop is skipped; zero chunk count and identity state checks are consistent.

## Limits, not defects

The oracle's Q/K/V, gates, beta and initial states are generated synthetic, with Q/K normalized; there is no production convolution/gate construction, actual captured input, FP16 output norm/gate/projection, session lifecycle, or model. It does not emulate the production four-partial FMA accumulation, `native::exp`/`rsqrt`, or serial GPU rounding. WY changes reduction/decay order. Therefore even a future successful CPU run can validate the equations/fixtures only, not exact Strata output parity or any new production tolerance. Per-chunk output and final state are compared; intermediate WY state matrices within a chunk are not separately materialized/compared, which is a coverage limit but not a demonstrated false pass or source defect. Physical counts and the MAX_BYTES cap do not prove device peak memory or GPU work-group resource viability; R82/R83 gates remain unchanged.
