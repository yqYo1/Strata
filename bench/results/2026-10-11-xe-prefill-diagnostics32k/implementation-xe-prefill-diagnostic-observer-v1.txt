transfer_ledger.validate API
----------------------------
validate(lines, *, expected_device, expected_stage, expected_pos0, expected_n,
         expected_chunk_limit, expected_mode, expected_issuer, expected_format,
         expected_layers=None)

lines: one stderr text string or an iterable of text lines. Text lines may have
LF/CRLF terminators. No byte decoding, whitespace normalization or log prefix
stripping occurs. Non-text and embedded line boundaries are rejected. Unrelated
stderr may occur before, between or after ledger lines; their text is ignored.
Any line containing the recognizable 'strata prefill expert' diagnostic family
must full-match one of the exact production row/total grammars; malformed,
truncated, prefixed, extra-field and oversized diagnostic lines are rejected.
The diagnostic-only line limit is 2048 characters, above the bounded production
uint64/int64/int32 row/total sizes. It is not a model/context cap.

Expected scope is mandatory and caller supplied. device is [0,INT32_MAX]; stage
is the nonempty half-open [LB,LE) with nonnegative signed-int64 endpoints;
pos0 is nonnegative signed-int64; n and chunk_limit are positive signed-int64.
pos0+n must fit signed-int64. Boolean values are not accepted as integers.
There is no hardcoded 262144 or 32768 model context cap. Empty Prefill runs do
not emit the source ledger, so n=0 is outside this completed-ledger API.

expected_mode is 'routed' or 'full_nonresident_stream'; expected_issuer is
'inline' or 'thread'. Each can alternatively be an exact mapping from ALL
local chunk offsets to the corresponding explicit string. The caller can thus
pin a tail mode/issuer change without the observer reconstructing stream_all,
STAGE, ring, worker policy or expert routing. Missing/extra/nonaligned map
keys are rejected. Routed rows require inline issuer, as in delivered source.
expected_format is 'native_gguf' or 'canonical_q2_0'.

expected_layers, if supplied, must contain every absolute stage layer exactly
once, keyed by integer layer number. Each record contains exactly blob_bytes,
gu_type and down_type. blob_bytes is positive uint64. Native type fields are
nonnegative signed-int32 values; this is not an enum whitelist or independent
layout verification. Canonical records require both type fields -1, matching
the diagnostic's no-native-type convention. Partial pin mappings are refused
instead of appearing fully pinned. Main obtains pins from its actual immutable
layout/configuration records; the parser does not inspect model blobs.

Without layer pins, the parser still requires a positive extent, valid format
type convention, and identical per-layer extent/type across all chunks. A
consistently wrong extent/type cannot be independently detected without caller
pins. The returned externally_pinned_layers boolean exposes this limitation.

The required row grid has ceil(n/chunk_limit) chunks. Rows must occur in exact
chunk-offset then ascending absolute-layer order. Each row's offset, pos0+offset,
min(chunk_limit,n-offset) tokens, device and stage must match. This both detects
duplicate/order errors and requires every layer, including calls=bytes=0 rows.
No unobserved expected grid is allocated or iterated; row expectations derive
from the observed row index, keeping malformed short captures cheap to reject.
Actual returned rows are stored, so parser memory scales with capture row count.

Counts, declared byte values and aggregate values must be nonnegative uint64,
with canonical decimal grammar and no signs or leading zeros. Native/canonical
type -1 is the sole signed exception. Each actual calls*blob_bytes product must
fit uint64 and exactly equal declared submitted_bytes. Per-mode cumulative
calls/bytes and their combined sums must also fit uint64. Python arbitrary-
precision arithmetic is used only to detect overflow, never to admit a value
the production uint64 accounting could not represent.

Exactly one total is mandatory and must follow all expected rows. Its exact
scope=this_prefill_stage_run, device, stage, pos0, n, chunks, per-mode totals,
combined totals, completion=checked and explanatory suffix are all checked.
Rows/another total after the first total, including a recognizable truncated
second ledger, fail. Missing ledger is an error, never zero. A zero total is
valid only with the complete exact zero-row grid and its one total.

Return: JSON-compatible dict with capture_valid, scope, complete rows, validated
total, per-layer metadata, external-pin coverage, completion_declaration and
independent_completion_validation=False. ValidationError subclasses ValueError.
The total's checked declaration is not independent verification of drains, DMA,
GPU state, process exit, model/request status or fault gates.

timer_overhead.validate API
--------------------------
validate(lines, *, timing_enabled)

timing_enabled must be an explicit Python bool supplied from Main's known
presence-based STRATA_PREFILL_TIMING expectation. Values '0' and '' still enable
the production diagnostic. This parser never reads the environment itself.
Recognizable 'strata prefill timer' lines require the exact distinct overhead
grammar. Existing 'strata prefill timing:' phase lines are ignored unchanged.

Enabled mode requires exactly one full completed overhead line, canonical
three-decimal finite nonnegative mark/fold host ms, and bounded uint64 integer
counts for marker_calls/new_events/fold_calls/intervals. Rounded 0.000 ms is
valid; signs, negative zero, NaN/Inf, decimal-to-float overflow, malformed fields,
missing/duplicate/second-run lines and integer overflow are rejected. Enforced
consistency: positive marker_calls, new_events<=marker_calls,
intervals<=marker_calls-1, and nonzero intervals require at least one fold call.
No expected count of underlying timestamp endpoint/API/UR calls is invented.

Disabled mode requires absence of the recognizable overhead diagnostic family,
including malformed family lines. The returned overhead is None, not fabricated
measured zeros. Return includes timing_enabled and capture_valid, with
independent_completion_validation=False. ValidationError subclasses ValueError.

The format has no device/stage/run identifier. Requiring one line rejects
multiple visible runs but cannot bind one line independently to a particular
run. Main must provide the complete, correct single-process/single-stage capture
and separately validate its origin and final model/process/fault status. Neither
observer can recover omitted bytes, prove no invisible second run, or identify
an unrecognizable fragment shorter than its diagnostic-family prefix.
